## 二、注入提示词（stat-prompt.js、combat-prompt.js、check-rolls.js、stat-coc-checks.js）

- 「前端」一律改「数值系统」（present 段、combat-prompt「前端卡牌系统」、check-rolls / coc「由前端按其强弱估算」→「由数值系统按其实力估算」）。
- 时间指代：指楼层统一「本楼 / 上一楼」；指一次生成用「本轮」；检定更正「上一层」→「上一轮」；mandates「刚才的…」→「上一楼的…」；「工作结果」→「打工结果」。
- `intimacy`：「尚未到亲密阶段」→「尚不满足亲密条件」，「用剧情施压」→「以剧情相逼」。
- `intimacyForced`：亲密改「亲密行为」，「按…芥蒂表现」→「按…芥蒂程度表现」。
- 压力行强度说明：上升、下降分开写（上升：小＝琐事烦心，中＝受批评、争吵，大＝重大失败、亲友出事；下降：小＝小憩，中＝娱乐、倾诉，大＝心事彻底解决）。
- 欲望行：「心动」→「被吸引」，「得手」「扫兴」改书面（与 4.2.5 第 6 条合并）。
- 口语与电报体：兜底→出面善后；走心→用心；挨批→受批评；本事→能力（sheets 段标题）；「未列出的技能按未学」→「视为未学」；「不写默认主角」→「不写角色名则指主角」；「同一角色同一技能一天一次」→「每天最多写一次」；diceManual、startfix、party、shortfall 句等按审查建议改成完整句。
- combat-prompt `NARRATION_HEAD`：删不存在的 `loot`，长句拆短；「顺手捡到」→「随手拾得」；「照战报」→「按战报」，落败 / 战败统一「战败」；「品相」→「品质」；元说明「程序会从背包里扣掉」→「物品会从背包中移除」；class 行「觉醒」→「获得新职业」；语法要求里「不要」→「不得」。
- check-rolls / coc：「偷偷行事」→「潜行」；「撩人」→「调情」；难度表重复一处删掉；「高技能」→「擅长技能」；奖 / 罚统一为奖励 / 惩罚。
- stat-engine「元叙事：」→「检定结果：」/「对抗结果：」，「vs」→「对」。
- 变动记录 note：「淡去」并入「淡忘」（芥蒂、欲望消退共用）；「开局修正·信任重」→「开局修正·信任（重）」。日结算「冷却」保留（用户未要求）。
