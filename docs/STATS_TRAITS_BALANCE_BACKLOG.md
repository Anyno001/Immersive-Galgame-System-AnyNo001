# 特质系统：平衡与提升待办（11-08 起，本地不推）

专门记录以后要做的平衡调整和玩法提升。逐项由用户拍板后再实施，实施完在条目后注明版本号。

## 一、平衡性

现有工具：`app/scripts/trait-balance-sim.mjs` 用固定随机数跑 30 楼，验收标准见脚本开头。以下调整先在模拟里跑，再改数值。

1. **门槛数值复核**：29 项六维门槛（docs/STATS_TRAITS_ATTR_GATE_PLAN.md）用真实建卡分布核对。手动建卡合计 72、单项 3–18，看主属性门槛 14 的特质，普通玩家能拿到几项。
2. **捆绑代价强弱**：每个系捆绑的代价是否和本体收益相当（第四节捆绑表），比如鹿系捆「害羞」偏轻、妖王系捆「控制狂」偏重。
3. **天生媚骨「招人觊觎」**：当前 ×1.5，叠加「花痴」时被 ×2 的上限截住。看多人同场时欲望是否膨胀过快。
4. **动物系新增 7 项**：鹰、鹿、鸟、龙、鬼魅、魔族、妖王，和原 7 系做横向比较，避免新系全面更强。
5. **格位压力**：捆绑占格后，常见配置（1 个系 + 捆绑 + 2 个自动）是否已经接近 5 格上限，必要时考虑把成就格并入总格，或给合成特质让出一格。
6. **门槛休眠的频率**：受伤、诅咒导致六维下降时，特质是否频繁闪灭。可能需要一个缓冲，比如跌破门槛满 1 天才休眠。
7. **懒虫遗留**：现在是「两天一次」，计划写的是「取差」，两者不一致（第二期遗留）。

## 三、提升性（11-08 用户定：11 项全部要做，待排期实施）

### 成长与转变

1. **特质进化**：特质满足条件后升级成高阶版本，原来的一格换成新的一格，不多占格子。例如：
   - 傲娇 → 坦率：对主角好感到「恋人」并持续 7 天，傲娇的减速消失；
   - 冰山 → 融化的冰山：信任满 80，冷却减半保留，上升减半取消；
   - 小蛇（蛇系）→ 龙系：剧情授予「化龙」时替换，逆鳞随之捆上。
2. **特质的反面觉醒**：压力转换「崩溃」恢复后，有概率把一个负面特质换成对应的正面特质（脆弱 → 坚韧已有，扩展到怕黑 → 夜猫子、社恐 → 社牛等）。
3. **隐藏特质**：副模型评定出、但不向玩家显示，直到触发条件第一次满足的那一楼才揭开，并发通知「发现了 TA 的另一面」。适合腹黑、病娇、斯德哥尔摩这类反差人设。

### 关系与互动

4. **特质相性**：两人各自的特质之间存在相生相克，比如犬系和猫系同场时彼此信任上升略慢、熊系和兔系同场时兔系压力下降略快。只做数值，并在角色卡里加一行相性提示。
5. **主角特质对 NPC 可见**：NPC 「了解」过半后，能「看出」主角的某个特质，好感结算时参考，例如看出主角是骗子后，信任上升减半。
6. **称号**：一个角色同时挂着两三项特定特质时，在名字旁边显示称号（只是装饰，不占格子，不改数值），例如「龙系 + 大佬 + 强势」显示「龙王」。和合成的区别是：称号只看组合，不产生效果。

### 题材与世界观

7. **世界观特质包**：按世界书题材（修仙、西幻、都市、末世、星际）提供一组只在这个题材下出现的特质，比如修仙有「灵根」（五行选一）、「道心」「心魔」，题材不符时不出现在候选里，减少候选表长度。
8. **种族字段**：现在用动物系或题材设定来表示种族。以后可以在角色卡里单独加一行「种族」，不影响数值，只用来让评选模型更准确地挑特质和捆绑项，也解决「懦弱的小蛇」这类种族和性格分离的问题。

### 易用性

9. **特质预览**：手动添加时，在候选项上显示「挂上后会连带捆绑：记仇」「挂上后占 2 格」，避免挂上才发现。
10. **评定历史**：每个角色的特质得失记一条时间线（第几楼、因为什么挂上或摘下），放在「编辑」区里，方便玩家理解为什么挂上了某个特质。
11. **一键重评**：单个角色的「重新评定特质」按钮，放在该角色的「编辑」区里（不放观赏区），配合「评定注意」修改后马上看效果。

## 四、特质与状态重构（11-08 与用户讨论定稿，待排期）

### 1. 判断标准
- 剧情里发生一件事就会结束 → **状态**；只能靠成长才变 → **特质**。
- 状态针对某个人 → **关系状态**。
- 怎么对待仇恨、恩情的性格（记仇、宽容、睚眦必报、以德报怨、一笑泯恩仇、知恩图报、忘恩负义、不愿亏欠）仍是特质。

### 2. 角色卡分栏
| 栏 | 内容 | 上限 | 占特质格 |
|---|---|---|---|
| 出身 | 种族、题材身份（狐妖、龙族、兽人、吸血鬼、人鱼、鬼、魔族、妖王、Alpha、哨兵、式神……） | 2 | 否 |
| 特质 | 性格、体质、天资、养成、恋爱人设、动物系（性格）、世界观职业 | 5（副模型自动评定最多 3） | 是 |
| 成就 | 系统授予 | 2 | 否 |
| 状态 | 个人状态 | 不设硬上限 | 否 |
| 关系 | 针对某人（恩情、仇怨、契约、青梅竹马……） | 每对关系每类 1 | 否 |

- 名字旁只显示最紧急的 1 个状态（受伤 > 生病 > 其他），其余显示「+N」。
- 观赏区只读，编辑全部收进「编辑」区（沿用已定版式）。

### 3. 动物系解耦
- 动物系是**性格**，所有世界观都能挂（现代世界观里像狐狸的人也可以挂狐系），占 1 格，捆绑项不另外占格。
- 种族放出身栏，只出现在相应世界观。种族**倾向**配对应的动物系性格，不强制（纯情狐妖、憨厚龙族都可以）。
- 鬼魅系、魔族系、妖王系整体移到出身栏，改名为鬼、魔族、妖王。龙拆成龙系（傲气，性格）和龙族（种族，捆逆鳞）。

### 4. 特殊特质
- 捆绑项：跟着本体，不占格，显示为本体胶囊上的附注。
- 合成：组成项占格，合成不额外占格，界面上折叠显示。
- 进化、反面觉醒：原地替换。
- 隐藏特质：占格，显示「？」，触发那一楼揭开。
- 称号：不占格，纯装饰。
- 成就授予的特质：进特质栏，满格时提示摘下一项。

### 5. 从特质表移出
- 个人状态：伪装身份、失忆、附身、随身、诅咒、旧伤、通缉犯、初体验、精神图景崩溃、斯德哥尔摩、已故。
- 关系状态：共犯、已标记、信息素契合、精神结合、认出蛋糕、伴侣印记、血契、主从契约、血仆、调教中、追悔、青梅竹马、白月光、命定之人；恩情、仇怨十项统一显示在关系栏；压力转换（崩溃等）显示在状态栏。
- 改为设置：豁免亲密门槛 → 编辑区开关；精神体 → 角色卡备注。
- 灰色项按我判定：前科犯、社畜、富二代、式神、使魔、契约者留作特质；受伤、失恋期、热恋期为状态。
- 旧存档键不变，只改归类与显示。
- **结怨不随时间淡化**（用户定）。性格宽容一类（宽容、以德报怨、老好人、一笑泯恩仇）才有淡化或更易解开的效果。

### 6. 时间系统：计时状态
| 类型 | 开始 | 结束 | 例 |
|---|---|---|---|
| 倒计时 | 标签、条件、手动 | 天数到 | 感冒、宿醉、失恋期 |
| 周期 | 日历自动 | 自动 | 生理期、发情期、易感期、月圆 |
| 恢复型 | 受伤 | 每天回血，治疗加速 | 轻伤、重伤 |
| 直到解除 | 标签 | 剧情事件 | 冷战中、中毒、诅咒、走火入魔 |
- 同一状态不叠加，只刷新天数；互斥状态互相替换；受伤只有一条。
- **自然回血**：每天回复最大生命 10%，重伤减半；自愈加倍，伤口难愈减半，贤惠、医术在场时略快。「自愈」「伤口难愈」改为作用在身体伤势上，误会账另外起名。
- **周期**：角色卡选填周期天数（默认 28）、持续天数（默认 5）、上次开始日，系统按日期挂上、摘下；正文标签「来了」可校准。需要开了日期捕捉；没开时只靠正文标签。
- **手动**：编辑区可以挂上、摘下状态，改剩余天数，设置周期或选「今天开始」，设置生命值；手动改过的状态 AI 标签不覆盖。
- 第一批周期接入：**待定**（候选：生理期、ABO 发情期和易感期、兽人发情季、狼人月圆）。

### 7. 状态的来源与注入
| src | 含义 | 注入正文 |
|---|---|---|
| setting | 开场评定读人设、世界书得来 | 否 |
| story | 剧情中由正文标签挂上 | 是 |
| system | 系统按条件自动挂 | 是 |
| cycle | 周期 | 是 |
| manual | 手动 | 是（可以单条关掉） |

- 副模型复核时同时判断来源；世界书后来写进去的改为 setting；setting 不会降回 story。
- 现有 5 项注入（无实体、已故、失忆、不眠、附身）改用这条规则。
- 特质仍一律不注入。
- 说明卡末尾显示浅色小字「来源：剧情 · 第 N 楼」，接上提升第 10 条的评定历史。

## 六、11-11 特质接入卡牌战斗（v2：已合入 Opus 审查意见，待实施）

### 0. 前置：战报补字段（A 类多条依赖）
- 战报伤势五档：无伤/轻伤/重创/濒死/倒下（battle-report.js:9），换算数值侧：重创=中伤，濒死、倒下=重伤。

- 「同场 NPC」统一定义为战报里的我方同伴；观战在场的人只用于已有规则。

### B. 奖励牌类偏向
- 机制：战利品候选走 fixedCandidates 均匀抽（rewards.js:183），不经过 weightOf；改为在其中加权抽，偏向类别 ×1.5。每个卡牌槽只有 2 张候选，35% 占比的类别出现率约 58%→70%，不算强。
- 只看主角特质，每人只生效 1 个；本职业池里该稀有度该类别少于 6 张时跳到下一个特质。
- 判类：攻击、格挡按牌类型与主效果；其余按「任意效果含」（能力牌首效果是 each-turn/buff，按首效果会误判）。
