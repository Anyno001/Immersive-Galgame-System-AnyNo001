# 数值表解耦计划（2026-11-05，本地不推）

## 起因
表格填了角色、设置器却显示没登记；AI 填表会改好感等数值；表格独有技能（园艺）与 IGS 互相覆盖；随身财物与物品表、金钱重复。
用户定：状态值（好感、信任、了解、芥蒂、体力、金钱、压力）归 IGS 管；表格里 AI 不许改，只做记录；用户在数据库里手改要同步回设置器。

## 一、表结构（IGS 适配版模板）

| 表 | 列 | 谁维护 |
|---|---|---|
| 角色数值表 | 角色姓名｜好感度｜信任度｜了解程度｜芥蒂程度｜体力｜金钱｜压力（主角也占一行，主角行关系四列留空） | IGS；AI 禁止修改 |
| 才艺技能表（新） | 角色姓名｜技能｜数值（一行一项，六维与特有技能都在这里） | IGS；AI 只可新增 IGS 没有的技能 |
| 主角信息表 | 删「基础属性」「特有属性」「随身财物」；加「已知秘密」「未知秘密」（主角自己的秘密：已暴露的 / 还藏着的） | AI |
| 重要角色表 | 删「基础属性」「特有属性」；加「已知秘密」「未知秘密」（从角色数值表搬来，含义不变） | AI |
| 物品表 | 不变；实物只记这里 | AI（战斗开启时程序接管） |

钱只记角色数值表的金钱（主角金钱 = 数值金钱 + 战斗积分，沿用 wallet 规则）。

## 二、改动来源与归属
- 数据库插件「开始填表」回调（tableFillStartCallbacks）到下一次「表格更新」回调之间的改动 = AI 填表：IGS 管的格子一律盖回 IGS 值。
- 不在填表窗口内的改动 = 用户手改：IGS 采纳，记为本聊天最近一楼的手动修改（meta.manual，重算/重 roll 保留，不受单楼与每日上限）。
- IGS 没有的项不碰。
- 才艺技能表里 AI 新增、IGS 没有的技能：IGS 首次读到时按表格值收进账本，之后归 IGS 管。
- 设置器手改 → 立即写回表格。同步子开关仍控制是否写表。

## 三、待定

- 已在玩的聊天迁移：旧表的秘密、属性格、随身财物搬到新位置（一次性，迁移前备份）。
- 旧模板（未换新模板）继续走现有字段映射层，不强制迁移。
