# 特质雷点计划（11-10，本地不推）

普通档下特质角色好感涨得偏快，原因是多数特质只有「涨得慢」，缺少「踩到就掉」。本计划为特质加入雷点：主角做了某件事，角色就扣好感。

## 用户已定

1. 新增 4 个中性事件标签供正文 AI 写：顶撞、命令、冷落、炫耀（「撒谎」已有「谎言揭穿」，不重复加）。
2. 雷、重雷两档在下一楼告诉正文 AI「某角色对上一楼的某事心里不快」，不说特质名；轻雷不提示。
3. 雷点先隐藏：踩过的显示在角色卡上；主角对该角色的「了解」过半时显示该角色全部雷点。

## 机制

### 触发信号

| 类型 | 写法 | 说明 |
|---|---|---|
| 事件 | `event:拒绝` 等 | 现有：拒绝、批评、夸奖、求助、失约、背叛、谎言揭穿、告白、约会；新增：顶撞、命令、冷落、炫耀 |
| 旁观 | `watch:亲密` / `watch:约会` | 主角同楼与他人亲密、约会，该角色在场 |
| 重复 | `repeat:约会` / `repeat:亲密` | 同一天对该角色第二次及以后 |
| 未到阶段 | `early:亲密` / `early:告白` | 好感未到「心动」时发生 |
| 当面战败 | `lose` | 主角战斗或挑战失败，该角色在场 |

### 三档效果

| 档 | 效果 |
|---|---|
| 轻雷 | 本楼该角色对主角的好感上升作废（含特质加成） |
| 雷 | 上升作废，好感再 −3 |
| 重雷 | 上升作废，好感 −8，芥蒂 +2 |

- 扣分是固定值，不乘特质倍率（蛇系这类「下降减半」不减雷点）。
- 同一楼同一角色踩到多个雷点，只取最重的一个。
- 每个角色每天因雷点扣的好感合计最多 15；下降单楼保护照常生效。
- 变动记录写「踩雷·强势：被顶撞」，计算明细列出档位与扣分。
- 雷、重雷时下一楼写入强制事项：「X 对上一楼主角⟨顶撞她⟩心里不快，本楼表现出来」，一楼最多一条，不提特质。

### 与现有规则的冲突处理

- 舔狗：不设雷点（设计就是被拒绝不降）。
- 占有狂：旁观雷只扣好感，不加芥蒂（保持现有「不加芥蒂、改加欲望压力」）。
- 追妻火葬场（追悔+强势+冷血）：芥蒂「明显」起，强势的「拒绝」雷点不生效。
- 女王、控制狂：被拒绝已加芥蒂，雷点只叠加好感部分，芥蒂不再重复加。

## 实施要点

- 新文件 `stat-trait-landmines.js`：登记表 `LANDMINES = [[特质, 触发, 档]]` 与判定函数；只从叶子模块（stat-vocab、stat-traits）导入，避免循环引用（见 v0.39.79）。
- 结算位置：特质钩子之后、日上限之前，读本楼 directives 与 ctx.changes；「上升作废」撤回本楼该角色好感正向变动。
- 新标签：`TRAIT_EVENTS` 加顶撞、命令、冷落、炫耀；正文提示词每个一句说明，只在真发生时写。
- 已知雷点存 `catalog.landmineKnown[角色][键] = 首次楼层`；角色卡特质胶囊下方加「已知雷点」一行，了解 ≥ 50 时全部显示。
- 强制事项复用 keyFumble 那一路的下一楼 mandates。
- 定向测试：每档一例、同楼取最重、每日 15 上限、占有狂不加芥蒂、追妻火葬场豁免、隐藏与了解过半显示。
