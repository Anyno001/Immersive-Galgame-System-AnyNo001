# 非人角色立绘系统方案（内测版）

> 状态：方案，未实施。仅内测版。
> 目标：妖魔鬼怪、怪物、使魔、坐骑、Boss 等非人角色拥有自己的长期立绘、CG 身份与演出，战斗与剧情通用。
> 前置：九尾、现出原形、照妖镜、兽影部件、人外特征贴片（`[igs-fx:traits]`）已于 10-22 删除。非人特征一律画进立绘本身，不用 SVG 贴片代替。
> 修订：10-22 自审后重写第 4–8 章（出图质量、姿态差分、战斗整合）；同日改为与人类方案完全分离，画布统一竖图、靠构图与溢出显示解决体型。

## 1. 原则

- **与人类方案完全分离**：非人角色是独立系统，写词任务、固定词、示例、差分规则、显示层、演出、声线都在新文件里；只共用底层设施（生图后端、存图、丢图兜底、角色档案存储）。
- **人类代码不改行为**：人类相关文件只在入口加一处分派「有 `creature` 档案 → 交给非人系统」，其余不动。新增回归测试：改动前后生成人类立绘、表情差分、CG 的完整提示词逐字比对，必须完全一致。
- **一个字段区分**：角色多一个 `creature` 档案；没有这个档案就是人。
- **全量支持**：半人形（兽人、人鱼、魔物娘等）与完全非人形都归非人系统，各有自己的固定词，不借用人类固定词；NSFW 立绘与 CG 沿用现有管线，不另设限制。
- **战斗不另起炉灶**：非人演出全部挂进现有战斗时间轴（`fx-battle-model.js` 的 encounter / hit / ko / result），不做第二套触发。

## 2. 数据：`creature` 档案

挂在角色 DNA 上（`scene/character-dna.js`，与 `views` 同级），缺省即人类：

| 字段 | 取值 | 说明 |
|---|---|---|
| `form` | `humanoid` / `beast` | 半人形 / 完全非人形 |
| `size` | `small` / `medium` / `large` / `giant` | 体型档 |
| `anchor` | `ground` / `float` | 落地 / 悬浮 |
| `temp` | 布尔 | 战斗中自动建档的临时怪物 |
| `group` | 布尔 | 成群出现的杂兵（哥布林群、蝙蝠群），见 §7.3 |
| `canvas` | `portrait`（默认）/ `square` / `landscape` | 仅手动改，不自动切换，见 §4 |

`normalizeCharacterDna` 负责校验与默认值；旧存档不迁移。

## 3. 识别：谁是非人角色

1. **手动**：角色设置页「立绘」区新增「非人角色」折叠项。
2. **AI 标注**：新指令 `[igs-fx:creature|名字|形态|体型|落地]`，只在首次出现或体型变化时写；条目说明开放给用户编辑，不做本地词库。
3. **战斗对手**：`[igs-fx:battle|对手|称号]` 的对手不在名单里时自动建临时档（默认 `beast` / `medium` / `ground`），同名不重复出图；临时档单独分组，可一键转正。

## 4. 出图质量（自审重点）

人类立绘的固定词是为半身站像写的（`BUILTIN_PROMPTS.sprite` 正向写死 `upper body, standing, facing viewer, looking at viewer, straight-on`，负向排除 `full body, feet`；`poseRule` 讲手部与衣装），非人角色不能沿用。人类固定词本身不改。

对策：

1. **独立的非人固定词**：新增 `BUILTIN_PROMPTS.creatureBeast` 与 `creatureHumanoid` 两套（只新增键，不改人类键），同样可在提示词子页改：
   - beast：`{tags}, no humans, solo, facing viewer, centered, {matte}`，取景词按体型拼入（见第 2 条）；负向排除 `1girl, 1boy, human, multiple views, scenery, floor` 等。
   - humanoid：`{tags}, solo, full body, facing viewer, centered, {matte}`；下半身形态是身份的一部分，蛇尾、鱼尾、蜘蛛下身不能被半身裁掉。
   - 非人版 `poseRule`：正面迎向镜头的战斗或待机架势，符合物种习性，长身形用立起、盘起、俯身前探收进画面。
2. **画布统一竖图，靠构图解决体型**：沿用 `spriteSize` 竖图（默认 `832x1216`），不自动切横图或方图。理由：手机舞台是竖的，横图在手机上要么很小、要么左右溢出且头部位置不可预测；战斗中正面迎敌比侧面图鉴更有压迫感；现有槽位、贴地、头部定位都按竖图设计；插件后端对横图的支持未经验证。各体型的构图：

   | 体型 | 构图（写进取景词） | 显示（见 §6） |
   |---|---|---|
   | small | 全身正面 | 缩小进槽位 |
   | medium | 全身正面，战斗架势 | 同人物大小 |
   | large | 全身正面，立起、盘起或俯身前探 | 放大，允许上下溢出 |
   | giant | 局部：仰视的上半身或头部，故意出框（`from below, upper body` 或 `close-up`、`out of frame`） | 铺满舞台并溢出，按头部对齐 |

   `canvas` 字段只供单个角色手动改为方图或横图，不自动判断。
3. **写词资料来源**：临时怪物只有名字时，照常读取人设、角色卡、世界书参考与本楼正文中对该怪物的描写；资料不足时由模型按物种常识设计，在 DNA 里写清种类、体型结构、肢体与器官数量、颜色、材质（鳞、甲壳、黏液、骨、雾）、标志部位。不写「scary」这类空泛形容。
4. **画师串**：现有分区画师串按区独立。新增「非人」分区，默认留空回落到通用串，用户可单独配偏写实或偏怪物设计的画师。
5. **透明底与抠图**：非人轮廓（触手、烟雾、火焰、半透明幽灵）沿用现有透明底流程；烟雾、火焰类允许保留半透明边缘，不强制硬边。
6. **非人示例与写词任务**：新文件 `prompt-tasks/creature.js` 自带建档、立绘、差分三段任务与非人示例（例如一只具体设计的岩甲蜥），不改 `sprite.js`、`expression.js`。

## 5. 差分：四档姿态，不是面部表情

人类表情差分（`prompt-tasks/expression.js`）只改眼、眉、嘴，固定词还是半身正面，不改它。很多怪物没有可读的五官，所以 beast 的差分在 `creature.js` 里另做为**整体姿态差分**：

| 档 | 用途 | 画面 | 映射到现有情绪（供回落链） |
|---|---|---|---|
| 常态 | 默认、待机 | 物种待机姿 | 平和 |
| 威吓 | 登场、咆哮、蓄力 | 张口、竖起、伏低前冲预备 | 愤怒 |
| 受创 | 被命中、残血 | 后仰、蜷缩、伤口发光 | 痛苦 |
| 狂暴 | 二阶段、反击、Boss 濒死 | 形体膨胀、发光、碎甲 | 实施时从现有高档情绪选 |

- 四档同一整套种子出图，写词只改姿态与状态词，身份 DNA 原样复用（与人物换表情不改脸同理）。
- humanoid 默认用完整情绪档（标签沿用 `MOOD_PRESET`，写词与固定词走非人版），可在设置里改为四档。
- 「击倒 / 消散」不出单独差分，由演出用「受创」图做消散（§7.2）。

## 6. 显示：体型、悬浮、巨型

非人显示逻辑放在新模块（如 `visual/igs-ui/creature-layout.js`），人类的 `resolveSpriteLayout`、贴地、槽位只在入口分派，不改计算。

- **体型缩放**：small 70%、medium 100%、large 135%，基于 `spriteDefaultScale`，数值可调。large 允许上下溢出舞台。
- **悬浮**：不按腿贴地，按图高居中偏上，带缓慢上下浮动。
- **溢出对齐**：放大后超出舞台时按头部锚点（`fx-anchor.js` 的头部识别）对齐，保证脸留在画面内，宁可裁掉脚和尾。手动改成方图或横图的角色同样按头部对齐，左右溢出可接受。
- **巨型（giant）**：
  - 不进同屏槽位，渲染在立绘层后、背景之上的独立层，铺满舞台并溢出，按头部对齐。
  - 人物照常站在前面，同屏容量不受占用；同时最多一只巨型怪，后来者取代前者。
  - 巨型怪在场时背景轻度压暗，避免与背景混在一起。
- `SLOT_CENTER_X` 不改。

## 7. 战斗整合（自审重点）

### 7.1 现状

- 已有：遭遇卡、逐招出手（命中 / 暴击 / 闪避 / 格挡 / 击倒 / 治疗）、结算卡、骰子大成功/大失败映射、战斗名牌。
- 对手图只用于名牌头像：`reader-host.js` 用 `floorAssets.sprite(battleFoe)` 取图，**对手不在名单里就没有图**，也不上舞台。
- 战斗规则禁止写血量，所以不能靠血量判断残血或二阶段。

### 7.2 补齐的战斗情形

| 情形 | 来源 | 演出（全部作用在对手立绘本身） |
|---|---|---|
| 对手上台 | `battle` 开战 | 对手立绘自动进入舞台（巨型进巨型层），遭遇卡期间用「威吓」档；普通怪从暗处推近，巨型怪画面低频震动、自下而上升起 |
| 我方打怪 | `hit` 目标是该怪 | 命中：白闪 + 后仰抖动，切「受创」后回落；暴击：加顿帧和更大位移；闪避：横向闪身残影；格挡：前推回弹 |
| 怪打我方 | `hit` 出手者是该怪 | 立绘前冲放大逼近镜头 + 画面震动，切「威吓」；命中玩家时画面边缘红闪（复用现有受击效果） |
| 怪治疗 / 回复 | `hit` 效果为治疗且出手者是怪 | 立绘泛光，回「常态」 |
| 击倒 | `hit` 结果为击倒，或 `battle-end` 胜利 | 「受创」图去色后碎散 / 化烟 / 沉入地面，按形态选一种；立绘离场 |
| 败北 / 撤退 | `battle-end` | 败北：怪保持「威吓」压近；撤退：怪留场、镜头后撤 |
| 二阶段 | 新指令 `[igs-fx:phase|名字]` | 狂暴登场：膨胀、发光、震屏，之后的战斗用「狂暴」档 |
| 收服 / 封印 | 神话包已有的 `subdue`（符 / 钵 / 葫芦 / 锁） | 改为作用在立绘本身：缩小、吸入法器；临时档询问是否转正成正式角色 |
| 战斗结束 | `battle-end` 后 | 未击倒的怪按「换场景立绘去留」规则留场或离场 |

### 7.3 多个对手

- 现有 `battle` 只带一个对手。扩展为 `[igs-fx:battle|对手1、对手2|称号]`，与 hit 目标名匹配。
- 同名杂兵（`group: true`）只出一张图，舞台上复制 2–3 个错位、缩放、前后虚化的身影，各自独立抖动；被击倒时逐个消散。
- 同屏上限：巨型 1 + 槽位怪最多 2，再多只在名牌里列出。

### 7.4 声音

- 咆哮、受创、消散三类音效按体型分档（小怪尖、巨型怪低频），复用神话包环境音。
- 非人声线（低吼、嘶鸣、虫鸣、幽灵低语）作为独立声线组，非人角色说话时代替语气音；人类 23 套声线不改。

### 7.5 非战斗互动

使魔、坐骑等常驻非人角色在剧情中只沿用普通立绘规则与四档差分，不单独做互动演出；神话包的 `pact`（契约）、`charm` 已可直接作用于其立绘。

## 8. CG

- 已登记的非人角色在 CG 中作为 `named` 出镜，复用其 DNA，不再退化为 `generic` / `object`。
- 未登记的路人怪物仍按 `generic` 处理。
- 战斗中的关键一击可按现有 CG 规则出战斗 CG，对手以 `named` 出镜。

## 9. 设置

- 「立绘」分类新增「非人角色」一组：总开关（默认开）、战斗对手自动建档（默认开）、体型缩放三项、巨型怪铺满舞台（默认开）、非人画师串。
- 「演出」分类新增「非人演出」开关（默认开，跟随战斗演出总开关）。
- 文案书面化、说明从简。
