# 亲密对决设计稿

本文件只留本地，提交时不暂存；若误推，推送时 `git rm --cached` 撤回。

## 0. 已拍板

- 底座复用日常挑战（`docs/DAILY_CHALLENGE_DESIGN.md`）：引擎、卡牌模板、种子重放、结算框架原样用，新增领域「亲密」。
- 两种机制：**合拍**（合作，决定这次顺不顺利）与**主导权**（对抗，抢主动权，适配强制爱、相爱相杀）。AI 在标签里按关系选，入口处玩家可以切换。
- 题材不设「不情愿」限制；玩家侧保留「停下」按钮，作为剧情外的退出，不算输、无代价。
- 不做外观或 DNA 推断年龄。唯一硬规则：角色档案**显式写明** 18 岁以下数字年龄时不出入口。未写年龄、写「成年」、外观娇小都照常。
- 立绘：对决期间用「动情」档表情（`scene/mood-groups.js`）；衣柜有「裸体」（`BUILTIN_NUDE_OUTFIT`，`scene/character-outfits.js:15`）时用裸体，没有就用当前衣服，不现场出图。
- 有手动「发起」按钮兜底 AI 漏写标签。
- 结局由设计者构想（见 §4）。

## 1. 开关与设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 亲密对决 | 关 | 需同时开 NSFW 总开关；关闭时提示词里不出现这段语法 |
| 我的位置 | 受方 | 受方 / 攻方 / 随剧情。决定玩家用哪套牌库，对方自动用另一套。入口处可临时改 |
| 发起按钮 | 开 | 见 §2.3 |

## 2. 触发

### 2.1 事件

一次「事件」= 连续的 NSFW 段（`romance-settings.resolveNsfwSpan`），跨楼延续算同一事件，出现一楼没有 NSFW 段即结束。事件键 = 连续段起始楼号，记在 chatMetadata，用于「每个事件只打一次」。

### 2.2 标签触发

AI 在楼末写 `[igs-challenge:标题|亲密|合拍或主导|难度]`，并停在悬念上。脚本只在**两个条件同时满足**时出入口：

1. 本楼开始了新的 NSFW 段（`continued` 为假，且该段在升温阶段，`resolveIntimatePhase` 返回 `rise`）。
2. 该事件尚未打过。

不满足时丢弃标签，记诊断码（`intimate-no-span`、`intimate-already-fought`）。第三项缺省或写错时按关系兜底：仇怨高于好感取「主导」，否则取「合拍」。

### 2.3 发起按钮

新事件的升温页上，若本楼没有亲密标签，阅读器角落出一个小「发起」按钮（实色、不描边，复用现有按钮 class）。点击后进入同一入口，难度取「普通」，机制按 §2.2 兜底规则选。事件已打过或翻过升温阶段后按钮消失。

必须适配窄屏阅读模式（现有窄屏阅读模式）：窄屏下按钮不能挡台词与工具栏，位置跟随窄屏布局另定，触屏点击区不小于常规按钮。验收时两种模式各截一张图。

### 2.4 入口

入口卡显示：机制（可切换）、我的位置（可切换）、「开始」「交给托管」「跳过」。跳过 = 让 AI 自己写，不结算，与日常挑战一致。

## 3. 说法与牌库

### 3.1 显示词

| 内部 | 合拍 | 主导权 |
| --- | --- | --- |
| 主角 hp | 氛围 | 掌控 |
| 敌方 hp | 隔阂 | 对方掌控 |
| damage / block | 靠近 / 稳住 | 进逼 / 招架 |
| vulnerable / weak / poison | 心动 / 慌乱 / 余温 | 破绽 / 动摇 / 沉溺 |

### 3.2 合拍牌库

- 受方：回应、主动一次、害羞躲闪（笨拙牌，结果随机：失败或逗笑对方大降隔阂）、牵住手、小声说喜欢。
- 攻方：温柔、安抚、耐心、情话、确认心意（抽牌）。
- 难关意图：紧张、羞涩、节奏不对、打断（手机响、门外脚步声，需「别管它」牌化解）。

### 3.3 主导权牌库

- 受方：欲拒还迎（招架后反击）、挑衅、示弱诱敌（先掉掌控，下回合双倍反击；对方意图为「观望」时落空）、反咬、撒娇夺权、咬唇忍住（招架）、勾手指（施加破绽）。
- 攻方：压制、逼近、扣住手腕（让对方下回合少一点精力）、低声命令（施加动摇）、抵墙（重击形）、不许躲（清掉对方招架）、耐心磨（沉溺，持续掉掌控）。
- 双方共用：撕扯（双方同时掉掌控）、旧账（伤害随仇怨与吵架次数上升，仇怨足够才进牌库）。
- 对方意图：反扑、挑衅、诱敌、强压、观望。按人设偏向：傲娇多挑衅，腹黑多诱敌，强势多强压；副 LLM 只挑意图模板键。

### 3.4 卡组来源

固定骨架 6 张 + 流派牌 10 张 + 关系牌 4 张，沿用日常挑战的 20 张规则与稀有度档。流派牌稀有度按相关技能值（魅力等，取自 `DEFAULT_SKILL_LIST`）；关系牌按好感或仇怨档位，相爱相杀关系的仇怨同样解锁狠牌。

## 4. 结局

结局全部由脚本查表判定，战报只写结局词与相对描述，不含数值，后续情节交 AI 续写。

### 4.1 合拍

| 结局 | 判定 | 战报基调 |
| --- | --- | --- |
| 水到渠成 | 胜，氛围剩六成以上 | 一切自然而然 |
| 小插曲 | 胜，氛围不足六成 | 有笨拙或笑场，反而更亲近 |
| 被打断 | 「打断」意图未化解且败 | 被外界打断，余温未散，留待下次 |
| 草草收场 | 败 | 节奏没对上，有点尴尬 |
| 心意相通（隐藏） | 胜，且触发过 3 次以上默契连击 | 不必言说的默契 |

### 4.2 主导权

| 结局 | 判定 | 战报基调 |
| --- | --- | --- |
| 我方主导 | 对方掌控先空，我方剩五成以上 | 此后由主角掌控节奏 |
| 险胜 | 对方掌控先空，我方不足五成 | 主角夺回主动，但对方随时会反扑 |
| 对方主导 | 我方掌控先空 | 此后由对方掌控节奏 |
| 反复易手（隐藏） | 主导权（双方掌控比例高低）易手 3 次以上 | 谁也不肯认输，相互撕扯 |
| 甘拜下风 | 玩家点「认输」 | 主角主动交出主导，剧情内的投降，与「停下」不同 |
| 同归于尽（隐藏） | 同一回合双方掌控一起归零 | 两败俱伤，难分彼此 |

「易手次数」由适配层逐回合比较双方掌控比例得出，引擎不改。

### 4.3 写回

- **战报**：用户楼插入，必写一句「此后由谁掌控节奏」或「这次进行得怎样」，让 AI 照此续写。
- **压力**：任何非「草草收场」结局压力下降一次。不扣好感。
- **主导印记**：主导权结局写在该角色身上。对方上次被压制，下次开局带「记仇」：首回合必定反扑。玩家上次落败，下次开局多一张「不服」。印记只存一层，新结局覆盖旧的。
- **默契**：合拍每次胜利，该角色的「紧张」难关层数减一，最低为零。第一次最难，越熟越顺。
- **回想图鉴**：每个角色记录点亮过的结局，第三阶段做。

## 5. 演出联动

- 对方血条降到一半以下：立绘切到动情档更强的差分。接近见底：衣柜有裸体则切裸体。
- 手牌边缘随对方心率微跳，心率取 `HEART_BPM`（`visual/igs-ui/romance-intimate.js:47`）按血条比例插值。
- 耳语类牌出牌时压暗半拍并响耳语音效，只这一下。
- 最后一两回合开启吱呀晃动，遵守 `rhythmSound` 开关，节奏慢、音量轻。
- 每回合对方一句短台词（副 LLM 按人设写，可接 TTS），血条越低越破碎。
- 结束时不出胜负大字：暗转后留一行结局小字，再插战报。

## 6. 分阶段

1. **最小可玩**：亲密领域、§2 触发与发起按钮、§3 牌库（先受方与攻方各一套）、§4 结局与写回、沿用日常皮肤。
2. **演出联动**：§5 全部，含立绘切换与心跳手牌。
3. **专属**：专属皮肤（近黑底、玫瑰色点缀，实色）、回想图鉴、好感或仇怨到顶后的两人独门牌（副 LLM 起名）。

## 8. 定向测试

- 无 NSFW 段的楼写了亲密标签：不出入口，记诊断。
- 同一事件第二次写标签：丢弃。
- 跨楼延续段不算新事件。
- 档案写明 17 岁：不出入口。档案写「娇小」、无年龄：正常出入口。
- 每个结局的判定边界各一条（含易手 3 次、同回合双零）。
- 印记覆盖与默契减层。

## 9. 第二阶段拍板（11-05）

- **NSFW 开关**：「NSFW自动生图」或「恋爱演出」任一开启即可（维持第一阶段实现）。
- **芥蒂维度（数值系统常驻）**：新增独立维度「芥蒂」，档位词 不满→记恨→怨恨→仇恨（0 档不显示），与好感、信任互不影响，可同时高（又爱又信任又恨）。所有开启数值系统的用户都有，普通剧情的宿敌也可用。需同步：`stat-state.js` 默认维度、`stat-vocab.js` 别名（恨、怨、敌意等）、`stat-metrics.js` 配色（用主题变量）、`stat-prompt.js` 维度说明（写短）、状态栏与二级页显示、世界书登记与表格模板若有维度清单也要同步。已有存档读到缺芥蒂的角色时按 0 补齐，不报错。芥蒂不进现有亲密门槛（`stat-prompt.js:109`）。
- **相爱相杀判定（芥蒂为主、信任为辅）**：好感高且芥蒂高时为相爱相杀，机制兜底取「主导」，「旧账」等狠牌按芥蒂强度解锁与变狠；信任低时额外加入少量「动摇」类牌。好感高、信任高、芥蒂也高时同样成立。替换第一阶段的「负好感当仇怨」。阈值按数值系统现有档位定，并在报告里列出。
- **新效果原语**：卡牌引擎新增三个效果，只新增不改已有效果，卡牌战斗的已有卡与种子重放不受影响：
  1. 延迟反击：本回合自掉掌控，下回合按倍数反击；对方下回合意图为「观望」则落空（示弱诱敌）。
  2. 双方同掉：对双方同时造成伤害（撕扯）。
  3. 二选一随机：按种子随机走两个效果分支之一（害羞躲闪：失败，或对方隔阂大降）。必须走引擎的确定性随机，禁用 `Math.random`。
- **立绘位置**：对决面板缩到一侧，对方立绘在另一侧清楚露出，不加遮罩；窄屏时立绘在面板上方露半身。
- **打到一半换装**：对方血条首次降到一半以下，立绘切到动情档更强的差分；首次降到两成以下且衣柜有「裸体」时换裸体。开局为当前衣服加动情表情（替换第一阶段的「开局即裸体」）。只升不降，回血不换回。
- 其余照 §5 演出联动全部做。
- **台词（11-05 拍板）**：复用战斗台词标签 `[igs-combat:lines|角色|…]` 与 `combat-lines.js` 的显示和 TTS。亲密标签所在战斗块里，AI 顺手写对方台词，阶段换成亲密版（开场、出招、受击、快失守）；只在亲密对决开启时进提示词。没有台词（发起按钮或 AI 漏写）时对方不说话，删掉本地短句兜底。
