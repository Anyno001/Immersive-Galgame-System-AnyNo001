## 行为

等待层位于舞台外，原工具栏无法穿过其层叠上下文；内嵌等待还会隐藏阅读器根节点。因此入口直接挂在等待层顶部，设置复用全局设置器，目录挂在当前可见的等待层宿主。

- 设置使用工具栏的 `settings` 齿轮，目录使用 `firstTurn` 书本；保留 `aria-label`、`title` 和 44px 点击区域。首次引导提示下移，避开入口。
- 关闭面板回到等待；选择已完成楼层只切换阅读源，不停止宿主生成。纯三点等待、内嵌与主动小游戏入口复用同一套回调。
- 等待期间选择当前已完成楼也重新打开历史快照，沿用 `turnOffset > 0` 的流式保护。后续 token 和完成事件不会抢回阅读位置；主动点最新时允许重新读取同一楼的新内容。
- 内嵌换宿主时移动现有目录面板，保留已选楼层；生成期间目录一直开着时，点「最新」读取点击时的宿主楼层列表。

## 改动归属

- `wait-stage-runtime.js`、`wait-stage.js`：顶部按钮、提示与样式。
- `reader-host.js`：回调接线、等待目录挂载和历史导航。
- `turn-index-panel.js`：已有面板换宿主，刷新最新目标。
- 不新增配置、存储结构、模型请求或抽象模块。
