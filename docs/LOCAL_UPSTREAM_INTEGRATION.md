## 功能取舍与接口迁移

- 保留内置 NAI 的单一 `imageTaskRuntime`／`runImageTask` 链、来源快照 `promptProvenance`、角色及场景固定 seed；`resolveImageSeed` 接受合法的 `0`。
- 保留命名衣装、DNA 和 `characterDefaultOutfits` 默认映射。旧原装图槽保留；普通保存不推断默认，不接入会清空旧槽的衣装迁移入口。
- 吸收整楼阅读准备、统一媒体缓存、页面资源租约、设置导航及宿主通道更新。服务和阅读器共用缓存 owner，测试退出停止服务并释放缓存。
- 审核采用改为异步权威 `readRecord()` 复核；有界展示元数据保留 `updatedAt` 和本图 `outfitSnapshot`。图片、状态或版本变化时拒绝采用。
- 修复图片加载请求的 Map 使用及迟到结果守卫；读取／解码失败终态精准失效楼层命中。单图缓存下等待当前表情，待加载引用进入页面租约，参考图仍优先使用已核验图片。
- 衣装时间线保留 `unknownOutfit`，别名与主名使用一致索引。显示临时图不登记衣装、DNA 或默认；角色资料读取仍限于全局和当前卡。
- 严格恢复媒体备份：坏结构／坏记录拒收，合法空旧备份可恢复；完整引用核查遇恢复未知或失败则拒绝删除。候选废弃经删除守卫，仍被引用时保留图片引用。
- CG 提交保留 `revisionToken`／`expectedToken`、`beforeCommit`／`shouldCommit`、`preserveBaseline` 和过期目标拒收；素材编辑继续使用事务内 revision 校验。二者是不同写入契约。
