# 数值关系压测讨论整理（11-07）

本地文档，不推送。接续 `STATS_STRENGTH_EXPANSION_PLAN.md`（强度扩展，子代理实施中）。本文是讨论记录与待拍板清单，未实施。

## 一、已定结论

- **NPC 之间的关系不碰。** 数值系统只记「角色对主角」，NPC 对 NPC 的关系交给世界书与正文上下文。理由：绝大多数情感线以主角为中心；AI 写关系文字易带刻板印象并被注入放大。
- **关系名不进提示词。** 31 条关系定义只给用户看，保持现状，名字不准也不会反过来影响剧情。

## 二、发现的问题

### 1. 芥蒂两路（吃醋）

现行：芥蒂 <26 吃醋不扣好感、好感 ≥50 掷骰可加、芥蒂 +2；芥蒂 ≥26 扣好感并按芥蒂掷骰再涨芥蒂（每日 +8 封顶）。思路认可，三处待补：

- **双算**：芥蒂加四档后，AI 可能在吃醋之外再写 grudge 上升。提示词加一句「吃醋已含芥蒂，不另写芥蒂标签」。
- **高路螺旋**：芥蒂越高越难过检定、越容易继续涨，且芥蒂不会自然消退。建议每过一天 −1，最低降到 25（不掉回低路）。
- **进高路更快**：芥蒂一次「大」+10，两三件事即到 26。判断为合理，告知手感会变。

### 2. 友情被恋爱向规则卡住

- 关口 50/75 只能靠约会、告白、共患难突破，纯朋友难过 50。
- 好感 50 以上的关系名几乎都是恋爱向（暧昧未明、情投意合等），挚友、家人、兄妹会被误标。阶段名（明确喜欢、强烈在意、深爱）同样偏恋爱。
- 关系名的偏差来自规则表，不是模型；名字只显示不注入。

建议：关键事件加友情向「交心」；关系名分恋爱 / 非恋爱两套，以「是否当过恋爱对象」区分（可复用修罗场判定，代码未核）；数值不分开。

### 3. 误会没有回滚

误会期间扣掉的信任、加上的芥蒂，真相大白后只能靠后续上升标签慢慢补；信任重大下降后有 3 天受伤期，上升减半。建议新增「误会解除」事件：一次退回因误会扣掉的部分信任，芥蒂降一档。

### 4. 迁怒被记到主角头上

好感标签只能写「对主角」。角色为他人发火时，AI 很可能写 `favor|角色|愤怒|大`，按负向不设上限每楼都扣，连带信任、芥蒂，几楼就从恋人掉到「爱而生疑」。

**强度扩展会放大这个风险**：方向词改为以情绪组名为主（愤怒、怀疑、不满），AI 更容易把「此刻情绪」写成好感方向。

建议：tags 段好感行加一句——「方向词写角色对主角态度的变化，不是角色此刻的情绪；角色为他人生气、迁怒或误会尚未落到主角身上时，不写好感。」猜疑交给信任下降，误会解开配合「误会解除」事件。

## 三、压测场景

做法：写脚本按楼喂预设标签序列给结算（不调 AI、不生成剧情），输出好感 / 信任 / 了解 / 芥蒂四条曲线与每楼关系名，生成双击即开的 HTML。等强度扩展实施和验收完成后再写，避免撞文件。

| 场景 | 要看什么 |
|---|---|
| 青梅竹马（纯友情） | 能否过 50/75；关系名是否被标成暧昧 |
| 家人、兄妹（起始「亲密」55） | 起步即过 50，关系名是否恋爱向 |
| 欢喜冤家、傲娇 | 好感与芥蒂同涨；同楼「感动+委屈」去重只留一条，另一种情绪丢失 |
| 前任、爱恨交织 | 高好感高芥蒂低信任，吃醋高路是否螺旋 |
| 背叛后和解 | 信任受伤期 + 芥蒂每日化解 10，几楼能修复 |
| 宿敌、惺惺相惜 | 好感负、信任高，欣赏与愤怒交替，关系名是否稳定 |
| 暗恋、单恋 | 好感高、了解低（雾里看花），心意槽与关口配合 |
| 修罗场多角 | 同楼两人吃醋，一低路一高路 |
| 师徒、主仆 | 害怕与欣赏混合，信任高、好感中等 |
| 困难档长线 | 30 天日常 + 偶发大事件，曲线是否过平 |
| **性质转变**（收养的妹妹：一起长大→得知无血缘生爱慕→被父母拆散→分居数年→重逢） | 起始亲密时关系名应为家人类；何时判定「当过恋爱对象」并切换关系名；拆散时芥蒂应指向主角还是父母（AI 能否分清）；`skip` 能否以年为单位、多年跳跃时日计数与受伤天数是否出错、长期不见好感是否消退（代码未核）；重逢落在爱恨交织 / 爱而生疑；告白能否突破 75、芥蒂几天化解 |
| **误会→真相**（青梅竹马男友怀疑主角与同学出轨，后发现两人是同父异母兄弟） | 男友对主角的信任、芥蒂在误会期掉多少，真相后多少楼恢复；有无「误会解除」事件对比；迁怒是否被写成对主角的好感下降。两兄弟之间的关系不在压测范围（NPC 之间不碰） |

## 四、用户 11-07 决定

- 迁怒说明句：并入正在实施的强度扩展（已通知子代理）。范围扩到「与主角无关的喜事」：角色因他人或与主角无关的事高兴、生气、迁怒，或误会尚未落到主角身上时，不写好感。
- 其余四项按推荐做：芥蒂两路三处修补、友情「交心」事件 + 关系名恋爱 / 非恋爱两套、「误会解除」事件、压测脚本。等强度扩展验收后另写实施计划。

### 无关喜事（考上大学、和父母和好）

角色自身的喜事不写好感，交给已有的东西：

- 角色心情：表情差分 / 情绪立绘本来就会显示喜悦，不需要数值。
- 若主角在其中有份（陪着复习、帮忙劝和、第一时间分享给主角），那份「被陪伴、被分享」才写好感（感动 / 安心，按强度）。
- 若角色主动第一个告诉主角，可以视为信任或了解的小幅上升，由 AI 按剧情判断，不强制。
- 暂不做「角色心情」数值：它会成为第二套情绪状态，与表情差分重复。

## 五、补充压测场景：癖好反转（11-07）

**设定**：主角为妻子，丈夫有绿帽癖，两人事先约定；第三者（黄毛）与主角当着丈夫亲近。测的是「表面像背叛、实际是双方同意的玩法」时，丈夫对主角的数值会不会被套路判错。主角没有好感条，主角自己的癖好无法用数值表达，只能放在剧情里。

| 节点 | 丈夫对主角应该怎么记 | 风险 |
|---|---|---|
| 起始 | 恋人（好感 80、信任 60、了解 70、欲望 15） | |
| 坦白癖好、主角接受 | 感动 + 信任上升（秘密被接纳） | 了解是丈夫对主角的认识，这里不动 |
| 按约定当面亲近 | 欲望上升；好感不动或小幅心动 | **AI 套路写成吃醋**：自动加芥蒂，芥蒂高时还扣好感 |
| 丈夫心里也有点酸 | 吃醋·小，走低路（芥蒂 <26 不扣好感、+2）——「酸但喜欢」正好对上 | 多楼累积芥蒂到 26 后转高路扣好感，是否合理待看曲线 |
| 事后安抚 | 安心 / 感动 | |
| 主角越过约定（瞒着私会） | 信任下降（中或大），可伴随受伤 | 癖好不等于同意欺骗：要看 AI 能否分清「约定内」与「越界」 |
| 修罗场演出 | 若主角与黄毛有恋爱演出，两人同场且本楼有吃醋标签会触发 | 剑拔弩张的演出与玩法基调不符；不写吃醋标签就不触发 |

**看出的问题**：吃醋标签被当成「看到伴侣和别人亲近」的固定反应，不看角色是否真的因此不满主角。欢喜冤家的玩笑醋、傲娇嘴硬也会被同样误判。

**建议**（与迁怒说明句同类，待拍板）：吃醋标签说明加一句「只在角色真的因此对主角不满时写；角色乐在其中或只是玩笑，不写吃醋」。不针对特定癖好写规则。

## 六、补充压测场景：双方同意的情绪玩法（11-07）

### A. BDSM 入门（已同意但很紧张）

两种视角都测：主角是紧张的一方时，紧张只能体现在主角压力；主角是带领的一方时，看伴侣对主角的信任与伴侣自己的压力（stress 带角色名）。

| 节点 | 应该怎么记 | 风险 |
|---|---|---|
| 开始前商量界限 | 伴侣信任上升（小或中） | |
| 过程中紧张 | 紧张一方压力上升·小 | 固定「当天第一次亲密压力 −10」会反着记 |
| 害怕但同意 | 不写好感 | AI 把「害怕」写成好感方向 → 负向好感 |
| 疼痛 | 不写伤势 | **AI 写 hurt 标签 → 进战斗账本扣生命** |
| 尊重叫停 | 信任上升·中 | |
| 无视叫停 | 信任重大下降 + 受伤期 3 天 | 能否与「同意范围内」区分 |
| 事后安抚 | 压力下降、安心 | |

### B. 夫妻情绪玩法（丈夫扮入室者强迫妻子，妻子哭着做到一半才发现是丈夫）

主角为妻子。数值记的是丈夫对主角；妻子自己的恐惧、愤怒只能落在主角压力上（主角无好感条，设计如此）。

| 节点 | 应该怎么记 | 风险 |
|---|---|---|
| 「入室者」出现 | 不给临时称呼建档 | AI 为「劫匪 / 陌生男人」建档并写芥蒂、好感，揭晓后成孤儿档案；系统无法合并到丈夫 |
| 被迫、哭泣 | 主角压力上升·大 | 固定 −10 让压力反降；「哭泣」组兜底为受伤·大，AI 若写到丈夫身上会重扣 |
| 揭晓是丈夫 | 主角压力部分回落；丈夫了解上升（看到妻子真实反应）、愧疚不计好感 | |
| 是否事先约定 | 约定过：玩法，信任可不变或上升；未约定：这是越界，但丈夫对主角的数值不该因此下降 | 妻子的愤怒无处可记，只能靠剧情；AI 可能错写成丈夫对主角的芥蒂 |

### 看出的问题与建议（待拍板）

1. **伤势**：总则加一句「伤势只记真实受伤：双方同意的玩法中的疼痛不写，非自愿造成的伤照写」。界线是是否同意，不是是否亲密。（伤势进战斗账本扣生命，误记影响最大）
2. **亲密压力**：去掉固定 −10，交给 stress 标签（上一节已提，本节两例都是反例）。
3. **哭泣组兜底**：由「受伤·大」改为「悲伤·小」。哭的原因太多（感动、玩法、委屈），兜底误判时损失要小；AI 明确写「受伤」仍按大算。（改动在正在实施的计划第八节）
4. **伪装 / 身份未明**：总则加一句「角色伪装或身份未揭晓时，按真实身份写标签，不为临时称呼建档」。

### C. 非自愿（极端压测）：舞会后台被强占，事后发现是必须要嫁的未婚夫，主角厌恶他

主角为受害方。界线已定：非自愿＝真实伤害，伤势、压力照记。

| 节点 | 应该怎么记 | 风险 |
|---|---|---|
| 被强占（身份未明） | 主角 hurt（若有身体伤害）、压力上升·大、体力扣除；按真实身份写标签，不为「陌生人」建档 | AI 为临时称呼建档；固定压力 −10 反向 |
| 揭晓是未婚夫 | 未婚夫对主角的数值按他自己的态度写（可能仍是好感高） | AI 按「亲密」给未婚夫写爱恋 / 欲望上升，或写 event |
| 主角厌恶他 | **无处可记** | 关系名只看未婚夫对主角的数值，可能显示「情投意合」「情热难抑」，与主角感受完全相反 |
| 被迫成婚 | 已有「亲密门槛按角色豁免（剧情所迫）」，可复用 | |

**看出的盲区**：数值全是「角色对主角」的单向记录，主角对角色的态度没有位置。平常问题不大，但在单向施害、单恋、利用这类关系里，关系名会给出与主角感受相反的结论。

**建议（待拍板）**：
- 关系名显示改成单向措辞：标题写「他 / 她对你」，避免读成双方关系。
- 「我对 TA」一栏：由用户手填（可选），只给用户看，也可选择注入提示词；不由 AI 写，不进数值。这样不会引入模型的刻板印象。

## 七、补充压测场景：邪教 / 克苏鲁 / 封闭村落（11-07，构想）

| 场景 | 触到的漏洞 |
|---|---|
| 1. 教团圣女视主角为神选者，狂热崇拜 | 好感、信任满格但出于信仰不是感情，关系名给出「灵犀相通」；「崇拜 / 敬畏 / 狂热」不在方向词与情绪组，整条丢弃 |
| 2. 目睹古神后角色癫狂大笑 | 「狂喜、兴奋」在大笑组，兜底成正向好感——发疯被记成对主角有好感 |
| 3. 村长被祭坛之物附身，同一副身体两种意识 | 标签写给村长还是附身者？现有「按真实身份写」只管伪装，不管附身 |
| 4. 全村几十个村民态度一致 | AI 写 favor\|村民们 → 建出名叫「村民们」的群体档案；逐个点名则档案与在场名单膨胀 |
| 5. 教团洗脑，角色一夜之间从仇视转为死忠 | 关口 25/50/75 拦住，只能靠 event 一档一档过；没有「剧情强制改值」的标签（start 只在首次出场有效） |
| 6. 祭品被献祭死亡后又在梦中出现 / 复活 | 死亡状态是否存在、死后标签是否继续结算，代码未核 |
| 7. 祭典轮回，时间回到第一天 | 时钟只能前进；轮回后数值该不该重置、了解是否保留（主角记得、角色不记得），无机制 |
| 8. 长期置身不可名状的恐怖 | 压力顶满 100 后只有检定 −10，没有崩溃 / 疯狂后果；CoC 理智与压力是否重复，代码未核 |
| 9. 无名之物、以「它」相称的存在 | 代词或无名称当角色名建档；与别名合并的问题同「伪装身份」 |

### 建议（待拍板）

- 提示词：附身时按「当下掌控身体的意识」写标签；群体不写关系标签，只对具名个人写；不为代词或无名称建档。（与伪装身份那句合并成一条「身份」规则）
- 兜底：大笑组改为平淡（大笑的原因太杂，喜悦组已覆盖正向）；与哭泣组改悲伤·小同理。
- 关系名：好感、信任都高但了解很低时，不给「灵犀相通 / 两心相许」这类相知类名字（与「我对 TA」、单向化一起改）。
- 剧情强制改值：可考虑 `[igs-stat:reset|角色名|关系档]`（洗脑、失忆、轮回），每角色每 N 天一次；先观察是否真的常用再做。
- 6、8 两项先核代码再定。

## 八、补充压测场景：主角离体（艳尸设定，11-07）

**设定**：主角已死，肉身留在原处被他人对待，主角以灵魂旁观剧情。同类：昏迷、灵魂出窍、互换身体、主角被附身。

| 节点 | 现状会怎样 | 问题 |
|---|---|---|
| 主角死亡 | 系统没有主角死亡 / 离体状态；生命只在战斗账本，倒下≠死亡 | 主角生活条照常结算 |
| 他人对肉身亲密 | intimate 标签照扣主角体力（`settleIntimate`），亲密门槛照查 | 尸身被扣体力、被算「亲密」 |
| 旁白写到进食、入睡 | 漏打兜底按旁白补进食、入睡（`fallbackDirectives`） | 灵魂「看着他吃饭」也可能被补成主角进食 |
| 主角检定 | 技能检定照常 | 灵体无法行动，检定无意义（除非设定可以影响现实） |
| NPC 对主角的好感 | 只能按「主角在过程中的态度」判断，但主角不再行动 | 好感应该记 NPC 对主角这个人（含对逝者的思念、愧疚），总则需要说明对象是人不是身体 |
| 关系名 | 对肉身有执念的角色显示「情热难抑」等 | 与主角感受相反，同「我对 TA」盲区 |
| 冷却 | 主角不在场 / 不互动，好感按天冷却 | 对逝者的感情不应自动冷却 |

### 建议（待拍板）

- 主角状态标签 `[igs-stat:hero|离体/复归]`（离体涵盖死亡、昏迷、出窍、被附身）。离体期间：主角体力、金钱、伤势、进食入睡兜底、亲密扣主角体力、主角检定全部冻结；压力保留（灵魂的感受）；NPC 关系标签照常结算；好感冷却暂停。
- 总则「身份」条补半句：关系标签记角色对主角这个人的态度，不记对其身体的态度。
- 与第二轮第八节「死亡状态」合并处理；状态栏显示「离体」。
