## 二、接口约定（各批共同遵守，A 批前由我定死）

### 1. 状态存档
```
catalog.statuses = {
  角色名: {
    状态键: {
      src: 'setting' | 'story' | 'system' | 'cycle' | 'manual',
      kind: 'timer' | 'cycle' | 'recover' | 'until',
      since: 游戏日, until?: 游戏日（timer 用）, floor: 挂上的楼号,
      toward?: 对象名（关系状态才有）,
      inject?: false（manual 单条关闭注入）, manualLock?: true（手动改过，AI 标签不覆盖）
    }
  }
}
catalog.cycles = { 角色名: { 周期键: { period: 28, length: 5, last: 游戏日, on: true } } }
```
- 关系状态（结怨、救命之恩、血契……）原本存在 character.relStates，**不搬数据**，只在读取层把它们并进「关系」栏显示。
- 恢复型状态「受伤」不另存，直接读战斗账本的 wound（生命百分比）。

### 2. 状态定义表（新文件 app/src/scene/stats/stat-status-defs.js）
行：`[显示名, 分组(个人|关系), 类型(kind), 默认天数, 世界观子类(空=通用), 注入句(含{{名}}), 效果说明, 互斥(逗号)]`

### 3. 读写接口（新文件 app/src/scene/stats/stat-status.js）
- `hasStatus(state, cat, name, key)` / `statusesOf(...)` / `applyStatusChange(cat, name, key, { on, src, days, toward, floor })`
- `advanceStatuses(cat, day, days)`：日结算推进，到期摘下、周期挂摘；返回 changes。
- `statusPromptLines(state, cat, present)`：只给在场角色、只给需要注入的，一状态一句；空则返回 []。

### 4. 正文标签
- `[igs-stat:status|角色名|状态名|开始/结束]`，关系状态加第五段对象名。
- 只在提示词里列「当前世界观可能出现、且不由系统自动挂」的状态名。

### 5. 结算明细（A 批定义，所有批次写 change 时都带上）
change 增加可选字段 `calc: [{ label, value }]`，例如
`[{label:'感动·中 基础',value:5},{label:'阶段倍率 明确喜欢',value:0.8},{label:'结果',value:4}]`，
以及 `capped: 'gate' | 'daily' | 'bigUsed' | null`、`traitTags: ['恋爱脑']`。

### D 批：时间系统 —— 受伤自然回血 + 周期
- 依赖：战报接入数值交付、B 批。
- 自然回血（用户 11-08 定，可选）：设置「回血方式」= 按楼 / 按天（默认按天）。
  - 按楼：每楼 1% / 3% / 5%（默认 3%）；只算 AI 楼，重新生成不重复计。
  - 按天：每天 5% / 10% / 15%（默认 10%）；日结算推进。
  - 时间跳跃（skip 标签、日期捕捉一次跳很多天）：两种方式都按「跳过的天数 × 每天比例」一次算完，按楼方式换算为每天 = 每楼比例 × 10，最多回满；回满后伤势、相关状态一并清除。跳过 7 天以上直接回满。
  - 重伤减半；自愈 ×2、伤口难愈 ×0.5、贤惠/医术在场略快（按楼方式只在其在场的楼生效）。
  - 写回战斗账本 wound（走现有 heal 入口，不另造通道）；倒下的同伴同样回血，回到 1 以上即可再参战。
- 日结算其他数值（用户 11-08 定，改 stat-day.js 与 stat-strain.js 的 relaxStress）：
  - 压力按比例回落：每天 −当前压力的 15%（向上取整，最少 −3），主角与 NPC 相同；沦陷、扭曲、蜕变仍不自然变化；痴迷未见主角仍 +5。乐天派等特质的额外下降照旧叠加。
  - 时间跳跃也减压：按天数一次算完（复利计算）；跳过 7 天以上直接降到 20（已低于 20 不动）。现在 settleSkip 完全不减压，要补。
  - 恋爱对象的欲望：每天也 −1，但只降到 25（非恋爱对象仍降到 0）；有「夜夜笙歌」「病娇（欲望不消退）」等特质的照旧按特质。
  - 信任、了解、金钱：不随日子变（维持现状）。
  - 芥蒂 >25 每天 −1、最低 25 维持不变；在变动记录与说明卡里写明「小心结需要剧情和解」。
  - 变动记录照 A 批的 calc 格式写明公式（例：压力 60→51：60×15%=9）。
- 「自愈」「伤口难愈」改为作用于身体伤势；误会账（RECENT_HURT_DAYS）的特质钩子改名，行为不变。
- 周期：角色卡选填周期天数（默认 28）、持续（默认 5）、上次开始日；有日期捕捉时自动挂摘，标签「来了」可校准。第一批：生理期、ABO 发情期/易感期（建议，待用户确认）。
- 编辑区「今天开始」按钮（接口先做，UI 在 F 批）。
