## 通用约束（四批都适用）

- 目录 `app/src/scene/stats/`。只改本批点名的内容，不顺手重构，不做额外排查。
- 不加新的正文标签，只用现有信号：事件（拒绝、批评、夸奖、求助、失约、守约、背叛、谎言揭穿、告白、约会、顶撞、命令、冷落、炫耀、重逢、提起）、关键事件（共患难、交心、托付、立誓）、旁观、同日重复、未到阶段、当面战败、在场名单、现有 flags。
- 特质一律不注入正文；下一楼强制事项不提特质名。
- 全部特质只改数值，不碰战斗与亲密对决的牌组、主导权、回合、牌效。
- 状态不可原地修改，沿用 withCharacter、展开拷贝的写法。新文件只从叶子模块导入，不导入 stat-traits.js 与规则文件（循环引用，见 v0.39.79）；特质判定由调用方以 has(名, 特质) 传入。
- 闭包级变量写在 return 之前。
- 共用文件（stat-settle.js、stat-traits.js、stat-trait-rules.js、stat-status-defs.js）其他批同时在改：每次编辑前重读，只动自己的行。
- Edit 会写成 CRLF：改完每个文件执行 `sed -i 's/\r$//'` 转回 LF。
- 说明文字用书面语，不出现开发用语，中英文之间不加空格。
- 只跑本批点名的测试文件（`node --test tests/文件名`，在 app 下），不跑全量、不 build、不提交、不升版本号。
- 交付时列出：改动文件、每项做了什么、没做成的项和原因。
