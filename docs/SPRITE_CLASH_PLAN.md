# 立绘碰撞演出计划（SPRITE_CLASH_PLAN）

> 2026-10-26 起草。本文件只留本地，不推云端（提交前 `git rm --cached`）。
> 路径均相对 `app/src/`。

## 0. 目标

正文出现「A 打/推/扑 B」时，A 的立绘冲到 B 身边接触，B 作出受力反应，同时播放对应音效（例：巴掌 →「啪！」）。B 单独在场时，A 临时从 B 身后探出完成动作，或者以画外一击的形式出现。竖屏是第一优先。

接触动作统一建模为「冲刺 → 接触 → 反应 → 回位」，打击、推搡、扑抱、击掌都复用这一套。

## 1. 审美约束（验收逐条核对）

- 不用色块或纯图形占位。残影、闪白、探出全部基于立绘自身复刻（同一张图加滤镜），不画手掌、星星、速度线色块。
- 头顶情绪符号（💢、晕圈）保留，沿用现有头顶符号实现。
- 拟声字「啪！」「咚！」与集中线只在漫画模式出现，普通模式只有动作和声音。
- 时长上限按 4.0 档位表（小 450ms、中 650ms、大 900ms），不拖慢翻页；同页最多播 2 次，超出只播声音。
- 样式不写死：时长、幅度走 CSS 变量和 class，跟随主题；不写内联 style 数值。
- 小、中、大三档都必须有明确的冲击感（用户 10-26 要求），档与档之间拉开差距，一眼能分辨。克制只体现在「不加图形元素」，不体现在削弱打击感。详见 4.0。
- 低画质：按 4.0 去掉残影和 contrast；`env.reduced`（减少动态）：只保留受击反应和音效，不做冲刺。

## 2. 触发

### 2.1 AI 标签（主路径，准确）

```
[igs-fx:clash|出手者|目标|动作|力度]
```

- 不能用 `contact`，该名称已被占用。
- 动作：中文词或英文 key，查第 3 节动作表，写错时按 `hit` 处理。
- 力度：轻 / 中 / 重（light / mid / heavy），省略时取动作的默认力度。
- 出手者可写 `{{user}}`、主角名或「旁白」；目标同理，目标为 User 时走 4.5 节。
- 加入 `FX_TAG_KINDS`，受标签演出总开关管；在 `fx-prompt.js` 补一段提示词（书面语、不穷举）。

### 2.2 正文自动识别（默认开，保守）

新增 `scene/clash-detect.js`：

- 句内出现动作词表（扇、掴、一巴掌、揍、踹、推开、撞上、扑进…怀里、抱住、击掌…）。
- 施方取句首主语，复用 `narration-sprite.js` 的 `subjectOf`（需导出）。
- 受方取动作词后最近的点名角色，复用 `namesOf` 或 `stage-cast.js` 的 `findCalledCast`。
- 只要施方或受方任一无法确定就不触发，宁可漏，不可错；受方为「他/她」代词且同屏只有 1 人时可认定为该人。
- 否定或假设语境跳过：「没有扇」「差点」「想要」「如果」「别」等前缀。
- 同一句已有 `clash` 标签时，自动识别让位。
- 设置项 `clash.auto`，默认 true。

|---|---|---|---|---|---|

| punch | 揍、拳、打了一拳 | 打击 | 中 | 碰即弹开，B 后仰 | 闷击 |
| kick | 踹、踢 | 打击 | 重 | 碰即弹开，B 后退 | 低频「咚」 |
| shove | 推、推开、搡 | 推搡 | 轻 | B 被推离 | 衣料摩擦 |
| bump | 撞上、撞个满怀 | 碰撞 | 轻 | 两人互相弹开 | 轻撞 |
| pat | 拍头、敲头、弹额头 | 轻触 | 轻 | B 缩一下 | 轻拍 |
| hug | 扑进怀里、抱住、扑上去 | 亲密 | 轻 | 冲刺后贴住，停留 1.2s 再缓慢分开 | 布料软响 |

## 4. 演出编排

用 Web Animations 实现，复用 `fx-sprite-react.js` 的 `reactSprite`，并新增 `dashSprite`。新模块 `visual/igs-ui/fx-clash.js`。

### 4.0 冲击三档（小 / 中 / 大）

所有打击类动作（slap、punch、kick、shove、bump、pat）都按档位取下表参数，参数写在 `clash-actions.js` 的 `CLASH_TIERS` 中。下文各路径里的数值以中档为例，小档、大档按此表替换。亲密类（hug、highfive）不吃本表。

| 参数 | 小 | 中 | 大 |
|---|---|---|---|
| 蓄力后仰 | 2% / 80ms | 4% / 100ms | 7% 加下蹲 / 160ms |
| 冲刺 | 140ms，无残影 | 110ms，2 张残影 | 80ms，3 张残影，冲刺时 A 拉伸 scaleX 1.06 |
| 命中定格 | 40ms | 80ms | 140ms，定格期间整个舞台 contrast(1.15) |
| B 闪白 | brightness(1.4) | brightness(1.8) | brightness(2.4)，加两次闪烁 |
| B 受力 | 偏移 3% / 旋转 2°，快速回弹 | 偏移 6% / 旋转 4°，回弹一次 | 击退 18%（踹可出画）/ 旋转 8°，230ms 后从原位淡回 |
| 震屏 | 1 次短促横震，幅度 4px | 2 次横震，幅度 9px | 4 次衰减震，幅度 16px，加 1 次纵向下沉 |
| 镜头 | 不动 | 朝命中点推近 1.03 | 推近 1.08 后快速回弹，背景沿打击方向扫动（`sweepBackground`） |
| 音效 | 原声，略轻 | 原声加一层低频 | 原声加低频轰，再叠 0.3s 尾音 |
| 头顶符号 | 💢 小 | 💢 | 晕圈或星点，停留 0.8s |
| 总长上限 | 450ms | 650ms | 900ms（击退淡回不计入） |

- 竖屏下震屏幅度与位移按 0.6 倍缩放，但定格时长、闪白强度、镜头推近不缩，保住冲击感。
- 低画质：去掉残影和 contrast，保留定格、闪白、震屏和音效。
- 全局震屏开关关闭时，以镜头推近和定格代偿，冲击感不能归零。
- 档位来源依次为：标签第 4 栏 → 正文强度词（狠狠、用力、一脚踹飞→大；轻轻、拍了拍→小）→ 动作默认力度。

### 4.1 双人同屏·横屏（平移版）

| 拍 | 时长 | A | B | 其他 |
|---|---|---|---|---|
| 蓄力 | 80ms | 往反方向平移约 4%，缩放 0.97 | — | — |
| 冲刺 | 120ms | 平移到接触点 | — | 2 张残影：A 立绘复刻，透明度 .35 → .15，依次滞后 30ms |
| 定格 | 70ms（重 120） | 停住 | brightness(1.8) 一帧 | 音效在此帧起播；同时 bark |
| 反应 | 200ms | — | 顺受力方向平移 6% 并旋转 3–5°，回弹 | 中档以上沿打击方向横震 |
| 回位 | 200ms | 退回原槽 | 头顶出 💢 或晕圈（打击类） | — |

接触点 = B 槽位中心 ∓（B 半宽 × 0.55），取自 `SLOT_CENTER_X` 和立绘实际宽度，A 不与 B 重合。

位移叠加：现有立绘 translate 由 `--igs-fx-huddle-dx` / `--igs-cast-sink` 合成，冲刺动画用 `composite:'add'`（`reactSprite` 已是 add），不覆盖撑伞靠拢等现有位移。

### 4.2 双人同屏·竖屏（纵深版）

竖屏槽位水平间距太短，改为：

- A 横向只走 50% 的距离，同时放大到 1.15 倍。
- 冲刺期间 A 的层级临时高于 B（加 class 抬 z-index，动画结束移除）。
- 命中时 A 压住 B 约半边身体，B 的反应以后仰、偏头为主，平移幅度减半。

判定竖屏沿用内嵌框和阅读器现有的竖屏标记，不自行重新判断。

### 4.3 单人：同屏模式未开，或某一方不在画面上

「单人」指用户没开同屏模式，画面上只有说话人一张主立绘 `#igs-sprite`；同屏模式开着但施方或受方不在 cast 里，也走这条路径。缺的那一方临时出现，打完即退。这是常规路径，不是降级，必须和双人一样有冲击感。

**临时层 `.igs-clash-ghost`**
- 挂在主立绘同一个舞台容器里，与 `#igs-sprite` 同级，不依赖 `#igs-cast` 是否存在，层级用 class 控制。
- 立绘取该角色当前衣服下的平和或默认表情（`resolveSpriteAsset`），高度、贴底规则与主立绘一致。
- 不进 cast 名单，不占槽位，不触发换人滤镜或说话人切换；演出结束、翻页、跳过时移除 DOM。
- 图片未解码完成就不等待，直接降级到 4.4，不能让演出卡住。

**情形 A：画面上是受方 B，缺施方 A（典型的「身后啪」）**
1. A 的临时层从 B 身后侧边（出手方向的反侧）滑入半身，160ms。此时压暗加模糊（`--igs-clash-ghost-dim`，默认 brightness(.72) blur(1px)），层级在 B 之后。
2. 蓄力：A 后仰。
3. 冲刺：A 层级抬到 B 之前，压暗和模糊同步褪掉，变回正常亮度，按档位冲向接触点。
4. 定格、闪白、音效、B 受力反应，全部按 4.0 的档位参数执行。
5. A 退回 B 身后，重新压暗，220ms 淡出。

**情形 B：画面上是施方 A，缺受方 B**
1. B 的临时层在 A 出手方向的一侧、画面内侧边滑入，140ms，正常亮度，层级在 A 之后。
2. A 冲刺到 B，命中后 B 按档位受力；大档时 B 直接被打出画面，不再淡回。
3. 小档、中档时 B 回弹后淡出，200ms。

**主立绘位移**：主立绘本来居中，冲刺与受力都用 composite:'add' 叠加，结束后自然回到原位，不改主立绘的布局变量。

**竖屏**：临时层与主立绘的水平距离按 4.2 的纵深处理，临时层宽度缩到主立绘的 0.9 倍，避免两张图挤满屏。

**降级**：取不到缺席一方的立绘（`hasSprite` 为假、资源解析为空或图片未就绪），降级到 4.4。

### 4.4 单人·画外一击（A 是 User、旁白或无立绘）

- 屏幕本身充当出手方。
- B 按受力方向偏头或后仰（旋转加短平移）。
- 舞台朝命中方向微推（复用 `pushStage` / `moveStage`），并播音效和震屏。
- 不画任何代表出手方的图形。

### 4.5 打 User（目标是 User，且 User 无同屏立绘）

- A 冲向镜头：缩放 1.0 → 1.25，同时下移，200ms。
- 定格后舞台整体往后一震。
- 四周压一圈暗角，300ms 收掉。暗角复用现有 vignette，不新建色块层。
- A 缩回原位。
- 若 User 有同屏立绘，按普通双人处理。

### 4.6 亲密类（hug）

- 冲刺后不弹开，A 停在接触点并与 B 轻微叠压（A 层级在前）。
- 停留 1.2s，缓慢回位 400ms。
- 不震屏，不闪白，不出 💢。
- 可接撑伞的靠拢变量，但不改那边的逻辑。

## 5. 音效与语气音

- 在 `fx-sfx.js` 的 `FX_SFX_PARTIALS` 加 slap / punch / kick / shove / bump / pat / hug / highfive 八种，沿用现有合成方式，按力度调增益和低频。
- 定格帧起播，和画面对齐。
- 受击方自动播一声 bark（`playVoiceBark`，情绪映射为痛或惊）；出手方不加 bark，避免吵。hug、highfive 不播受击 bark。
- TTS 正在朗读时，音效照播，bark 让位（沿用现有让位规则）。

## 6. 漫画模式附加

- 命中点叠一个手写拟声字（复用 `ONOMATOPOEIA_PARTIALS`，补「啪！」「咚！」「砰！」），加一圈短集中线（复用 `igs-fx-speedlines`）。
- 只在漫画模式开启时出现。

## 7. 与战斗演出的关系

- 战斗中的 `[igs-fx:hit|…]` 目前只有受击方反应，出手方不动。
- 阶段 3 可选：出手者与目标都在场时，复用本模块的冲刺和回位（受击反应仍走战斗现有的 `reactSprite`），由战斗设置里的新开关「出手冲刺」控制，默认关。
- 阶段 1、2 不动战斗代码。
