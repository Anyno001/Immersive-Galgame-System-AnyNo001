# TTS 整楼缓存与声音库

基线为远端 `v0.39.25`（`fc7a57d`），源码风险 R3。本 PR 不改版本或生成发布产物；同一运行代码的本地候选 `0.39.27` 另供试用。

## 原因与处理

原整楼预载只在阅读器换入新回复后启动，并逐页等待；开着等待小游戏、打开已有楼层或中途开启整楼开关时，没有及时准备全楼。下一页预取还会等本页所有分段下载及 1.5 秒停留，短句容易出现播放空档。

改为宿主主生成完成后立即准备整楼，不依赖阅读器是否打开；阅读器已有楼层也会补齐。下一页在正常阅读时立即入队，快翻只合并 400 毫秒。所有语音请求共用五路队列，缓存命中不占新槽位，正在排队的预取被当前播放复用时提升优先级。

原预取通过文字外形猜类型，不携带完整性别上下文；耳语还可能继承上一页。现在整楼使用分页后的类型、角色主名、情绪、读音规则与上下文；聊天气泡复用播放构造器，普通与窄屏重听都使用统一语气提示。TTS 耳语按语义分页及亲密设置决定，不再取决于是否已渲染出某个演出 DOM。

原普通内存缓存仅六十条；没有 Cache Storage 时，整楼后半部分可能挤掉前半部分。当前楼另保留最多 32 MiB 的压缩音频，不保留解码 PCM；相同楼层、配置下的正文修订可以复用已完成音频，换聊天或分支、关闭功能、销毁、清理缓存时释放。

## 模块边界

- `tts-request-queue.js`：网络并发、播放优先级、排队取消；429 遵守响应中的退避时间，否则指数退避，最多重试两次，并降低并发、逐步恢复。
- `tts-floor-plan.js`：正文过滤、分页、普通台词／旁白与聊天气泡的语音计划。
- `chat-tts-line.js`：气泡实际播放与预生成的同一份参数构造。
- `tts-floor-preloader.js`：整楼身份、同楼去重、设置更新与生命周期取消。
- `tts-floor-audio-cache.js`：当前楼有容量限制的压缩音频保留。
- 原 `tts.js` 继续负责 provider 参数、缓存键、在途请求合并、解码与播放；`reader-host.js` 和 `bootstrap.js` 只接入现有事件及分页入口。

新增模块均低于六百行，没有引入运行时依赖或存储迁移。API 地址、Key、免费／付费模型和声音选择保持用户配置。

## 声音库分类

每条声音可选中文、日文、英文、韩文、法文、德文、西班牙文、葡萄牙文、俄文、意大利文、阿拉伯文和粤语，默认未设置。这里只记录分类，不强制语言或改变声线选择。

主接口与旁白独立接口分别在 `voiceLibrary.languages` 按声音 ID 保存语言，`voiceLibrary.folders` 保存文件夹、归属和折叠状态；旧 `voices` 字符串保持兼容。新增、批量识别或获取音色后，原声音分类保持；改 ID 迁移分类，删声音清理元信息，删除文件夹只把条目移回未分类。分类随设置导入、导出与备份保存。

界面复用角色素材的文件夹栏和移动图标；`folder-state.js` 抽出原素材文件夹的纯操作，原存储格式及作用域保持。声音库不展示图片网格切换，沿用设置配色、按钮、原生下拉与弹窗；桌面同一行显示名称、ID、语言和操作，手机宽度下 ID 独占下一行。

## 验证

### 选声入口补充

基于 v0.39.33，角色台词、心里话、男女默认声音池、主库旁白及独立库旁白统一按各自声音库文件夹分组，并在声音名称后显示已选语言；未设语言不添加标记。未分类放在末尾，空文件夹不列出，声音库折叠状态不影响选声。没有文件夹时保持平铺。原生下拉沿用 optgroup，默认池复用素材文件夹标题与既有点选按钮，不新增主题。自动、同台词等首项及库外已保存声音保持，保存的仍为声音 ID，不改变生成请求或缓存。

定向用例 `tests/tts-voice-options.test.js` 从实际角色控件和设置控制器验证分组、语言、主库与旁白库隔离、库外值、默认池点选和分类删除后的选中值。

此次补充执行 `tts-voice-options`、`tts-voice-library`、`tts`、`settings-immutable-store` 共 95 项用例，全部通过；构建和 loader 构建成功。本地选声分类测试 JSON 内置程序与本次 bundle 一致，回读后执行冷启动、楼层完成预载、同楼缓存复用、销毁及重启通过。Chrome 桌面及 390 像素窄屏点验默认池和旁白选择，分类、语言与选中值正确，未见控制台错误；真实酒馆及手机未验收。本地候选沿用 0.39.33，并明确标为「选声音分类测试」，素材固定到已发布 v0.39.33；不覆盖正式发布文件。

### 选声搜索补充

各 TTS 选声入口添加搜索框，按声音名称、ID、语言做部分匹配，不区分大小写；空格分隔的条件取交集，如「日文 少女」。语言支持中文名、常用别名和代码，如「日语」「英语」「ja」「en」。未设语言不由声音名称猜测分类。主库、旁白独立库和各角色、默认池的查询互相独立。

输入仅就地过滤，不写草稿或整页重绘；会话内选择、改语言或改库触发重绘后，继续按最新库筛选并恢复输入焦点。原生下拉始终保留自动项及当前选中值，不匹配的已选声音单列提示；默认池隐藏不匹配项但不取消勾选，并按匹配结果更新文件夹计数。清空搜索恢复全部，无匹配显示提示。

本次执行选声搜索、选声分组、声音库、TTS、设置只读保护及设置交互共 104 项定向用例，全部通过。用例包含真实挂载的搜索输入、不保存及不失焦、下拉选中值保留、默认池搜索和勾选、重绘按新库刷新及焦点选区恢复。构建与本地 JSON 内置程序的冷启动、完成事件预载、同楼缓存复用、销毁及重启通过。Chrome 桌面和 390 像素窄屏实际点验组合搜索、重绘保留选中值及筛选后选声，无控制台错误；真实酒馆和手机仍待验收。

## 试用与未验证范围

保留「提前生成下一页」「新楼层预载全楼」开关。生成一楼后，即使还停留在等待页，也会开始缓存；打开旧楼时也会准备。建议测试一楼超过六十页、频繁切页、退出等待页及回到首页。

本 PR 只含源码、契约、说明与脱敏行为回归，不含 dist、loader 或本地导入件，不更改版本与标签；未混入此前手机呼吸候选。真实 Fish Audio、真实酒馆、手机解码及网络延迟未验收，不能把模拟并发提升直接换算成真实提速倍数。后续由用户试用反馈决定发布及是否另做流式播放。

五路额度只覆盖本实例的语音生成；同账号其他应用、其他标签页及拉取音色列表仍可能与它共享服务端限额。当前楼超过 32 MiB 时仍会回收最早音频，持久缓存可用时继续回读。免费服务本身的排队或延迟不由客户端保证。
