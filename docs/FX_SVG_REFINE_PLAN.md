## 0. 执行者须知

### 0.1 项目背景
- IGS 是 SillyTavern 上的视觉小说阅读器。画面由厚涂风格的背景图和角色立绘组成，「演出」是叠加在画面上的短时效果，由 AI 正文里的标签 `[igs-fx:名称|参数…]` 触发，或按地点、天气、情绪自动触发。
- 代码根目录：`app/src/visual/igs-ui/`（下文路径都相对于它，除非写明）。
- 演出构建函数的通用形态：`名称(item, env) { …; return { layer, life, sounds, node }; }`。`layer` 是挂载层（under 在立绘后、stage 在舞台、front 在最前），`life` 是毫秒寿命，`sounds` 是音效键名数组，`node` 是 DOM 节点。样式写在同名的 `*-style.js` 里，是一段 CSS 文本。
- 可复用的能力（优先使用，不要另造）：
  - 立绘动作：`sprite-actions.js` 的 `playSpriteSpec(el, spec)`、`SPRITE_ACTION_FRAMES`（hop、recoil、sink、sway、lunge、nod、shake、tremble、retreat）；`fx-sprite-react.js` 的 `reactSprite()`、`pushStage()`（整台轻推近）。
  - 震屏：`stage-shake-runtime.js` 的 `applyStageShakeEffect`；战斗里的 `shake(state,'light'|'heavy')`。
  - 镜头：`camera-shots.js` 的手持晃动与甩镜；`fx-camera-style.js` 里的 `.igs-cm-vignette`（暗角）、`.igs-cm-flash`（闪白）、`.igs-cm-doorlight`（门缝光）。
  - 漫画符号：`fx-symbols.js` 的 `MANGA_SYMBOL_SVG`，已有 heart、sweat、blush、steam、sigh、gloom（阴影竖线）、sparkle、tears、darkface 等。
  - 环境音：`scene-audio.js` 的 `resolveAmbientPlan()` 与图层；各包音效在 `*-sfx.js`。

### 0.2 用户的审美规则（判断依据）
1. 盖在厚涂画面上、**冒充实物、人物、动物、场景**的扁平图形最廉价，例如剪影小人、实色灯笼、黄黑胶带、木门板。
2. **漫画符号与漫画表达用户很喜欢**：头顶情绪符号、漫画泡、集中线、速度线、少女漫画花背景。这些一律不改。需要保留的物件图形，可以参考漫画符号的画法重画：墨线加白色外描边，造型夸张简洁，一眼看出是风格化。
3. 合理的物理现象可以用雾和光，比如浴室蒸汽加柔光、茶烟、冬天呼气。问题在于把同一种改色雾气套在抽象概念上凑数，ABO 信息素就是这样。
4. 动作、动物、场景物件能用镜头、声音或光影表达的，就不要画。例：有猫只出猫叫；下跪只用镜头晃动下沉。
5. **只改本文列出的项，其余一律保持现状。** 不要顺手删改。书信、纸页、圣旨、告示、UI 面板、手机、弹幕、CG 入场样式、对话框皮肤、句末等待符、战斗斩线、法阵、蛋糕、戒指、骰子等道具都不在本次范围内。
6. 立绘身上只允许一眼可辨的漫画记号，不贴模拟真实汗滴、痕迹的图形。
7. 不用左侧描边强调条，不做密集纹样，不用 emoji。
8. **劣质的光影同样是整改对象。** 用光代替物件时，光本身必须精致，标准见 0.4 节。
9. 需要用大块遮挡的场合（电梯门、偷看的门缝与窗框），用**纯黑遮罩**（类似电影遮幅）配合镜头聚焦与轻微晃动，不用带颜色、带纹理的门板或窗框。纯黑遮挡的违和感最低。

### 0.3 性能预算（项目近期在排查手机发热，必须遵守）
- 只动画 `transform` 与 `opacity`。不要对大面积元素做持续的 `filter: blur()`、`backdrop-filter` 或 `box-shadow` 动画。柔边一律用预先画好的渐变（`radial-gradient`/`linear-gradient` 加透明过渡）。
- 不新增常驻无限循环动画。持续类演出只在区间内运行，退出时移除节点或停止动画。
- 不新增每帧 JS（`requestAnimationFrame` 循环）。一次性动画用 WAAPI（`element.animate`）或 CSS keyframes。
- 单个演出新增 DOM 节点不超过 12 个，粒子类不超过 8 个。
- `mask-image` 只允许在演出生效期间挂在一个图层上。
- 音频：单个演出新增的持续音频节点不超过 4 个，结束时必须断开（参照 `scene-audio.js` 中 `layer.transient` 与 `disposeLayer` 的写法）。
- 降级：`#igs-overlay[data-igs-quality="low"]` 和 `prefers-reduced-motion` 下，只保留静态调色、字卡与声音，去掉粒子与持续动画。现有代码里 `env.reduced` 表示减少动态。

### 0.4 光影质量标准
- 不出现可辨认的几何边界：光斑不能是正圆或有硬边的色块，光带边缘必须柔和渐变。
- 颜色以场景滤镜的色温为底，事件色只做轻微偏色，饱和度不高于 35%；不用荧光绿、正红等高饱和固有色。
- 混合模式用 `screen`、`soft-light`；亮部不过曝成白块，最亮处不透明度不高于 .4（闪白类瞬时效果除外）。
- 光要有来源：从画面边缘、灯位、门窗方向来，落在立绘或背景上；不放没有来源的悬浮发光团。
- **火花与光点**：不用星形、十字形、圆点式的卡通火花。火花应是细长的短亮线，带运动方向，0.2–0.4s 内迅速衰减；单次不超过 8 粒；颜色偏暖白，不用彩色。光点（如人群光斑、荧光棒虚化）要有大小、明暗差异，不能等大等距排列。
- 不确定是否达标时，以截图为准，宁可不加。

### 0.5 工程规则
- 新增的颜色、尺寸写进对应 `*-style.js` 的 CSS，复用现有主题变量与 class。坐标类（`left:x%`）可以沿用现有 builder 的写法。
- 闭包里新增的 `const` 要放在 `return` 之前，否则会被 esbuild 当死代码删掉。
- 缓存或共享配置对象不许原地修改。
- 保持被改文件原有的行尾格式（本仓库工作区为 CRLF）。
- 不要修改 `tts.js`，它由另一项工作负责。
- 测试只跑相关文件：在 `app/` 下运行 `node --test tests/<相关>.test.js`，不跑全量，也不跑 `npm run gate`。完成后运行 `npm.cmd run build`，并在 `dist/igs.bundle.js` 中能搜到新增的 class 名。
- 截图验收用 `app/scripts/fx-shot.mjs`，它使用真实背景与立绘。截图含真实立绘，只能存在仓库外（如 `G:\奶龙Code\gal\演出版面审查截图\`），绝不提交。

## 3. 第二批：用户点名的演出

### 3.1 ABO 信息素：从「改色雾」改为分事件设计
- 位置：`fx-abo-build.js`、`fx-abo-style.js`、`fx-abo-sfx.js`；共用雾 `fx-mist.js` 的 `spawnMist()`。
- 问题：scent、scentlink、soothe 等都用同一种改色雾团（三个正圆渐变叠加，整体 `blur(14px)`），再加一根 22px 粗的雾线。每个事件意义不同，画面却几乎一样，显得敷衍；大面积 blur 也耗性能。
- 原则：ABO 小说里，信息素是被闻到的、有名字的气味。画面应该表现谁散发、谁闻到、闻到后有什么反应。用漫画符号、立绘反应、字卡和声音组合，不再用雾。

| 标签 | 新表现 | 复用或新增 |
|---|---|---|
| `scent` 释放信息素 | ① 释放者身侧飘出 2–3 道**漫画气味波浪线**（漫画里表示香味的弯曲细线），朝接收者方向延伸后淡出；② 信息素名称字卡保留（如「白桃」「雪松」），排版像香水标签；③ 接收者若在场，立绘微微前倾（`sway` 或 lean 1.2%），头顶出 `blush` 或 `sparkle` 符号；④ 整台极轻暖偏色（`soft-light` 静态渐变，强度 ≤ 8%）；⑤ 声音沿用 `abo-waft`，接收者处叠一声吸气 | 新增漫画符号 `scent`（波浪线），画法与 `fx-symbols.js` 现有符号一致：墨线加白外描边，颜色取信息素色 |
| `scentlink` 两人信息素交缠 | 两人各自飘出波浪线，在中间交缠成一个结后消散；两人前倾动作保留（已有）；交汇时出一个小 `heart` 符号；声音沿用 `abo-link`，叠心跳 | 删除 22px 雾线 |
| `soothe` 安抚 | 安抚者的波浪线变得平缓，绕到被安抚者身边；被安抚者立绘肩部放松（sink 1%，然后回正），头顶出 `sigh` 符号；配长呼气 | 复用 `sigh` |
| `suppress` 压制 | 不用雾也不用线：暗角收紧，被压制者额头出 `gloom` 阴影竖线符号，立绘去饱和约 15% 并 `tremble`（已有），整台极轻低频震动；配低沉嗡鸣 | 删除现有的头部三圈扩散环 |
| `bond` 标记 | 按已定规则：咬痕、印记改为漫画记号（沿用现有符号画法）加立绘 jolt、闷响，补一张小字卡「临时标记」或「终身标记」。终身标记的金光脉冲保留 | 新增咬合闷响 |
| `nest` 筑巢 | 删除 6 件衣服的 SVG；保留「筑巢中」徽章、立绘下沉与暖色；加布料窸窣声 | — |

- `fx-mist.js` 本身不删。浴室、茶、呼气等物理雾气按用户意见保持现状。只把 ABO 的调用（`fx-abo-build.js` 中所有 `spawnMist`）替换掉。
- 性能：波浪线是小 SVG，只动 `transform`/`opacity`；单次演出符号加线不超过 8 个；不使用 blur。
- 验收：scent、scentlink、soothe、suppress 各一张截图。画面中不再出现彩色雾团；能看出谁散发、谁被影响。
