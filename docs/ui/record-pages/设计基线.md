# IGS 资料界面视觉概念

## 交付范围
为地图、心事（日记）、物品栏、人际关系生成同系列界面概念图。仅新增本目录设计产物；不改业务源码、版本、构建产物，不提交或发布。图中文字、人物和地点均为虚构展示内容，不代表真实数据库记录。

## 已核实的参考边界
- 当前项目：`Immersive-Galgame-System-AnyNo001`。
- 默认对话框：底色 `rgba(31,34,37,.62)`、文字 `#d8d5cf`、圆角 `8px`，无描边、无投影、默认无模糊；真源为 `app/src/visual/igs-ui/original-reader-source.js` 第 42、119 行。
- 渐变黑幕：全宽贴合左右与底边，自下向上淡出，不使用毛玻璃；参考 `app/src/visual/igs-ui/CONTRACT.md` 第 21–22 行。
- 心事和物品栏沿用当前场景背景，标题分别为“珍藏心事”“你的背包”；返回图形轻量，实际触控命中区保留 44px。
- 地图只将有坐标的记录放为定位针，无坐标内容保留列表；点击地点与发送消息分离，不改变已有草稿安全边界。
- 资料只读，不添加装备、丢弃、编辑、关系数值等未经要求的数据或操作。

## 四屏设计方向
1. 地图：二维矢量地图、清晰地块与路径、可点击针形标记；表现普通、当前、选中状态，选中地点显示名称、描述与相关人员。
2. 心事：按人物组织的简洁日记册入口与按日期排列的篇章，阅读区用深色书页与留白承载文字，不用写实纸张纹理。
3. 物品栏：规整 RPG 格位、单色图标、右下角数量，选中物品后显示名称与描述。
4. 人际关系：相关人员索引与所选人物描述；只为有明确记录的关系展示连线或关联条目，不推断关系。

## 可实现性约束
- 界面材质使用 CSS 渐变、透明色、细线、轻阴影、Grid/Flex 与少量伪元素，不依赖整屏贴图。
- 地图路径、定位针和图标可以用内联 SVG 实现；点击、切换、缩放由 JavaScript 承接，不宣称 CSS 单独完成业务交互。
- 背景图与已有头像属于可替换内容资产，不与装饰层烘焙为一张图；无头像可用姓名首字或中性轮廓。
- 不使用金属雕花、复杂三维书本、皮革或手绘边框，不画新增数值机制。
- 概念图只验证视觉方向，不能替代真实浏览器布局、可访问性与交互验收。
