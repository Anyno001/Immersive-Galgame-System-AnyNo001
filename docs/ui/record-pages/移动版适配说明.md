# IGS 资料界面 · 移动版视觉稿

## 范围
沿用助手已认可的四张桌面设计图，生成四张独立竖屏移动版概念图。只新增本目录设计产物，不修改业务源码、版本、构建产物，不提交或发布。

参考图：上级目录 `01-地图.png`、`02-珍藏心事.png`、`03-你的背包.png`、`04-人际关系.png`。

## 共同视觉
- 深灰半透明面板、暖灰白文字、细线图标、克制的选中轮廓、微圆角、自下向上加深的黑幕。
- 延续已认可图片的细宋体标题与正文气质，不换为霓虹、金属或商业手游风格。
- 背景使用可替换的场景图片；界面文字、按钮、定位针与图标保持独立，不烘焙到背景。
- 目标约 390×844 CSS 像素的手机纵向视口；生图请求约 9:19.5 比例，实际导出尺寸以工具结果为准。
- 顶部为安全区与居中标题，底部留出手势安全区。小图形使用不小于 44×44 CSS 像素的透明点击区域。
- 正文目标 15–16px、辅助文字不低于约 12px；生成图的字体与精确尺寸需在实际页面中实现和验证。

## 布局重排
1. 地图：地图占上半屏主要空间，普通针、已选针、当前位置分开表达；桌面右栏改为底部详情面板，相关人员横排，保留前往按钮。缩放与归位控件位于地图区域，不与详情或安全区重叠。
2. 珍藏心事：顶部横向日记册选择，紧凑日期选择，正文单列阅读；上一则/下一则置于阅读区底部。不把桌面左右栏压缩并排。
3. 你的背包：三列格位，数量仍位于右下；所选物品详情放在格位下方，避免遮挡格位。不添加装备、出售或丢弃功能。
4. 人际关系：横向人员选择、简洁局部关系图、下方人物描述；节点与连线标签避免重叠，不缩小三栏桌面界面硬塞手机。

## 实现边界
- 布局、黑幕、面板、格位、文字、选中状态可用 HTML/CSS 实现。
- 地图路径、定位针、图标和关系连线用 SVG；点击、平移、缩放、切换和滚动状态由 JavaScript 承接。
- 城市建筑、水面、环境光等为背景美术资产，不承诺纯 CSS 逐像素复现。
- 不用手机设备外框、透视样机、鼠标光标表达手机效果；输出为完整平面界面。
- 图中人物、地点、日记和物品均为虚构示例。静态概念图不代表已实现触控、无障碍或响应式适配。
