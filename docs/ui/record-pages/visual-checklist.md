# 四页视觉验收清单（步骤 1 建立，步骤 7 终验）

参考图与哈希见 `reference-manifest.json`。本清单逐页对应八图结构；待校准数字以 `〔待校准〕` 标记，步骤 2 以真实组件截图冻结到 token。

## 共同项（八图一致）

| 检查项 | 依据 | 通过标准 |
|---|---|---|
| 配色 | 霜夜炭灰 + 暖灰白；面板 `rgba(31,34,37,.62)`、文字 `#d8d5cf` | 同一 token 驱动，无金色/霓虹/毛玻璃 |
| 标题 | 居中标题 + 两侧短线 | 几何居中偏差 ≤ 约 2 CSS px〔待校准〕 |
| 返回 | 左上轻量箭头 | 图形约 20–22px，命中区 ≥ 44×44 CSS px |
| 黑幕 | 底部向上渐变（bottom .92 / 中 .55 / 顶 .18 起点） | 承托文字不死黑〔待校准〕 |
| 字体 | Source Han Serif CN 400；拉丁/日期可 Cormorant Garamond | `document.fonts` 实际命中，不伪造细体档位 |
| 正文 | 宽屏 17–18px / 窄屏 15–16px，行高 1.75–1.85 | 不整体 scale 缩小 |
| 层次 | 透明背景 + 黑幕，内容顺序电脑分栏/手机纵向 | 不整图铺底叠透明按钮 |
| 附属物 | 无假状态栏/鼠标光标/装饰诗句/固定示例人物 | 截图中不出现 |

## 地图（D-MAP / M-MAP）

- [ ] 独立干净底图（`assets/map-demo-clean.png`，SHA-256 `8B740CA9…3510`），无文字/针/UI 残影
- [ ] 针三态可区分：普通 / 选中（细环）/ 当前位置（实心圆+圈）
- [ ] 桌面：地图约 72% + 右侧详情约 28%（最小约 280px）；详情含已选地点名、描述、相关人员（首字圆标+姓名）与“前往”
- [ ] 手机：上地图下详情，详情默认约 35–40% 高、可展开至约 70%；面板顶部圆角约 20px
- [ ] 缩放 +/− 与归位控件在地图区内，不与详情/安全区重叠
- [ ] 底部提示“拖动浏览 · 点击定位针查看”同款轻量样式
- [ ] 坐标投影按原图自然宽高等比；手机取景变化但锚点与地物一致
- [ ] 无坐标记录进地点列表；无底图只画中性坐标平面

## 心事（D-DIARY / M-DIARY）

- [ ] 书册：矩形、细书脊、SVG 书本、窄书签；禁棕色皮革
- [ ] 桌面：左册架/目录约 32% + 右阅读约 68%；篇章列表日期+篇名，选中细线/短线
- [ ] 阅读区：作者 · 日期、篇名大标题、正文深色书页；底部 上一则 / 01 / 03 / 下一则
- [ ] 手机：顶部横向书册、横向日期入口、单列正文、底部前后篇
- [ ] 篇章数无上限，不只放三则；边界 disabled

## 背包（D-BAG / M-BAG）

- [ ] 桌面五列、手机三列、极窄两列；格位微圆角细线
- [ ] 图标细线 `currentColor`；名称常驻（选中不消失）；数量右下角 `×值`
- [ ] 缺数量不显示角标；零显示 ×0；长名称最多两行
- [ ] 选中格 1px 暖灰轮廓；详情含大图标、名称、数量一次、描述
- [ ] 空槽仅禁用占位，不可聚焦/点击
- [ ] 手机详情在格位下方，不遮格位

## 关系（D-REL / M-REL）

- [ ] 桌面：人员索引约 22% + 局部关系图约 40% + 描述约 38%
- [ ] 手机：横向人员选择 → 局部关系图 → 描述/关联条目
- [ ] 首字圆标、细连线、线标签避让节点；节点可聚焦按钮
- [ ] 详情：圆标+姓名+身份、人物描述、相关人员列表（姓名 — 关系）
- [ ] 无显式关系不画边；描述提及人名不产生边

## 截图命名与复现

- 命名：`<页面>-<端>-<容器尺寸>-<状态>.png`，如 `map-desktop-1440x900-bookstore-selected.png`
- 状态固定：地图选旧书店/当前位置临河街道；心事选林夏册首篇；背包选旧钥匙；关系选林夏
- 采集：`preview:records`（步骤 2 建立）导入生产控制器/样式 + fake 客户端；关动画、等 `document.fonts.ready` 与图片解码；记录浏览器、DPR、提交哈希
- 对照：原截图 + 参考并排 + 约 50% 叠加；归一仅等比缩放
