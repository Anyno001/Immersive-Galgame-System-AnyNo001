# 封印类演出整改计划（2026-10-24）

本文可以单独交给执行者阅读，不依赖任何对话记录。通用规则（审美规则、性能预算、光影质量标准、工程规则）与 `docs/FX_SVG_REFINE_PLAN.md` 第 0 节相同，执行前先读那一节；本文只写差异和具体条目。

---

## 0. 背景与方向

- 涉及的是神怪包（`fx-myth.js`、`fx-myth-style.js`、`fx-myth-sfx.js`、`fx-myth-model.js`）里的四个演出：`subdue`（降妖收服 / 封印）、`formation`（法阵）、`barrier`（结界）、`pact`（血契印记）。代码根目录 `app/src/visual/igs-ui/`。
- 现状：这几个演出都是在厚涂画面上**用 SVG 线稿硬画**——地面一张旋转的圆环+六芒星法阵、线框穹顶、折线锁链加菱形锁、椭圆描边金钵、无限循环的漩涡圈。用户认为这是「强行画法阵」，观感廉价。
- 方向：**用光、声音、立绘反应和字卡表达「施法 / 封印」**，不画几何图案。基本节奏是「地面（或法器方向）先起金光 → 光把目标笼住或压住 → 立绘做出被封印的反应 → 法器专属的声音收尾 → 字卡落下」。
- 光的标准按 `FX_SVG_REFINE_PLAN.md` 0.4：光要有来源（地面、画面上缘、画面侧缘），柔边渐变、无硬边几何；颜色偏暖金，饱和度不高于 35%；亮部不透明度不高于 .4（瞬时闪白除外）；`screen` / `soft-light` 混合。
- 字卡（阵名、「敕令」、「封」、「血契」等书法字）用户喜欢，**保留并沿用现有 `.igs-myth-name` 写法**。
- 范围外：换装演出 `dressup` 的魔法阵换皮（`fx-daily.js:672-686`）、战斗斩线、CG 入场、对话框皮肤。不要顺手改。

## 1. 共用部件（先做，后面各条复用）

在 `fx-myth.js` / `fx-myth-style.js` 里新增，命名以 `igs-myth-` 开头：

1. **地面光 `groundGlow`**：落在目标脚下的一片横向椭圆柔光（`radial-gradient` 由中心暖金到透明，宽约 1.6 倍立绘宽、高约 8% 舞台高），`screen` 混合。动画只动 `opacity` 和 `transform: scaleX`：先从中心向两侧铺开，再缓慢起伏一次。挂在 `under` 层（立绘后），让光像是从地面打亮立绘脚边。
2. **升光 `riseLight`**：从地面光向上的一道竖向柔光幕（`linear-gradient` 自下而上由暖金到透明，左右边缘也要渐隐），`transform: translateY / scaleY` 自下而上升起，覆盖立绘下半身到胸口。挂 `stage` 层，`soft-light` 混合，最亮不高于 .3。
3. **底光打亮立绘**：用现有 `spritePulse(env, who, filters, ms)` 给目标立绘一次 `brightness(1) → brightness(1.12) sepia(.15) → brightness(1)` 的短暂暖亮，模拟被地面光打亮。不新增 filter 持续动画。
4. 降级：低画质与 `env.reduced` 下，地面光只做静态淡入淡出，不做升光和 scale 动画；字卡和声音保留。

## 2. 条目

### 2.1 `formation` 法阵（`fx-myth.js:122-138`，样式 `fx-myth-style.js:65-80`）
- 删：SVG 圆环、六边形、双三角、刻度线（`.igs-myth-ground`、`.igs-myth-spin`、`.igs-myth-line`、`.igs-myth-tick` 在本演出里的使用），以及 `break` 的碎片 `shardHtml(..., 'is-form')`。
- **不是一大片光，而是「阵眼」光点按阵型排布、有前后深浅**（用户 10-24 明确要求）：
  - 地面是一个透视平面：舞台中下部，纵向约 58%–86% 舞台高。光点越靠后（越靠上）越小、越暗、越扁，越靠前越大、越亮；最后排大小约为最前排的 45%、亮度约 50%。每个光点都是横向椭圆柔光（`radial-gradient`，无硬边），不画连线、不画圆环。
  - 阵型在 `fx-myth.js` 写成常量 `FORMATION_LAYOUTS`，每种是一组地面坐标 `[x, depth]`（depth 0 最前、1 最后），由 builder 换算成屏幕位置、大小、不透明度。至少四种：
    - `ring` 圆阵：8 点等角分布在透视椭圆上（前排两点自然更大更亮）。
    - `bagua` 八卦：8 点外圈 + 中心 1 点，中心最后亮。
    - `qixing` 七星（北斗）：7 点呈勺形，从斗柄末端依次亮起。
    - `square` 方阵：3×3 网格，按由前到后逐排亮起。
  - 阵型选择：阵名里含「八卦」「两仪」「四象」→ `bagua`；含「七星」「北斗」「天罡」→ `qixing`；含「方」「九宫」「军阵」「大阵」→ `square`；其余按阵名字符串哈希在四种里稳定取一种（同名阵每次一样）。
  - 光点总数不超过 9 个（符合粒子上限），每点一个节点；整个演出新增节点不超过 12 个。
- **open（布阵）**：光点按阵型规定的顺序依次亮起（相邻间隔约 120ms），每点亮起时 `opacity` 0 → 目标值、`scale` .6 → 1；全部亮起后整体一起做一次亮度起伏（非无限）；随后在场立绘做一次底光打亮。阵名字卡保留。声音沿用 `myth-formation`，可在每点亮起时叠一声很轻的高音 glint（`fx-myth-sfx.js` 现有 `glints()`），总共不超过 9 声。
- **enter（入阵）**：在 open 的基础上保留现有整台色调 `.igs-myth-tint`（multiply .2，颜色随光色）；立绘一次轻微 `sink` 下沉表示被困（`sprite-actions.js` 的 `SPRITE_ACTION_FRAMES.sink`）。
- **break（破阵）**：光点先全部亮到最亮，再从前排到后排依次熄灭（每点 .35 → .1 → .3 → 0 快闪后熄），最后一次闪白（复用 `.igs-myth-flash.is-soft`）和轻震屏（现有 `shake(env, 80, 5)`）。不画碎片。声音沿用 `myth-break`。

### 2.2 `barrier` 结界（`fx-myth.js:266-278`，样式 `fx-myth-style.js:81-86`）
- 删：线框穹顶 SVG、`.igs-myth-grow`、`.igs-myth-pulse` 的椭圆描边圈、`break` 的碎片。
- **open**：地面光 + 升光，升光高度拉满到舞台上沿以下 15%，颜色偏冷青白（饱和度 ≤ 30%）；升光到顶后，画面左右两侧边缘各出现一道极淡的竖向冷光（贴边，`linear-gradient` 由边向内渐隐，宽约 6%），表示罩子的边界，停留后淡出。可以在穹顶区域加一层极淡的 `soft-light` 冷色调（≤ .12），表示被罩住。声音沿用 `myth-barrier`。
- **break**：两侧边缘光与冷色调先一起变亮，再快速闪烁两次后熄灭；闪白 + 轻震屏。声音沿用 `myth-break`。

### 2.3 `subdue` 降妖收服 / 封印（`fx-myth.js:208-264`，样式 `fx-myth-style.js:134-148`，音效 `fx-myth-sfx.js:126-145`）
四种法器统一节奏：**光起 → 压制 → 收尾声 → 字卡**。删去所有 `.igs-myth-ring`（红圈、白圈）和 SVG 锁链、菱形锁、椭圆金钵、葫芦光球、漩涡圈（`.igs-myth-vortex` 目前是 `infinite` 循环，违反性能预算，必须去掉）。

- **符咒 talisman（默认）**：
  - 符纸是用户认得出的道具，**保留一张**，但按漫画符号画法重画：竖长纸条、墨线描边加白色外描边、纸面暖黄不透明、朱砂「敕令」两字；参考 `fx-symbols.js` 现有符号的线宽与描边做法。符纸从画面外甩入，拍在目标胸口高度一侧（沿用现有 `--sx` 位置），拍上瞬间立绘 `recoil` 一次。
  - 拍上后：目标脚下地面光起，升光一次，目标立绘 `tremble` 约 600ms，额头出 `gloom` 漫画符号（`fx-symbols.js`）。
  - 字卡：「封」。声音沿用 `myth-seal-talisman`。
- **金钵 bowl**：
  - 不画钵。光源在画面上缘：一道自上而下的暖金光锥（`linear-gradient` 由上到下渐隐，左右边缘柔化，宽约 1.4 倍立绘宽）压到目标身上；目标立绘 `sink` 下沉并去饱和约 15%（一次性 WAAPI，结束恢复）。
  - 同时脚下地面光亮起，与光锥上下相接。字卡「金钵」。声音沿用 `myth-seal-bowl`（钟磬）。
- **葫芦 gourd**：
  - 不画葫芦和光球。光源在画面侧上角（沿用现有 `gx` 的左右判断）：那一角先出现一团柔边暖光（来源光，贴边，不悬浮在画面中间），随后目标立绘沿现有的吸入动画缩小、旋转、移向那一角（`fx-myth.js:246-254` 的关键帧保留）。
  - 吸入过程中画面在那一角方向做一次轻微的 `pushStage` 推近。字卡「收」。声音沿用 `myth-seal-gourd`。
- **锁链 chain**：
  - 不画锁链和锁。改为两到三道横向的暖白窄光带（柔边，高约 1.2% 舞台高，宽约 1.3 倍立绘宽），从立绘两侧向中间收紧（`scaleX` 由 1.6 到 1），依次落在胸口、腰、膝的高度，每道收紧时立绘 `tremble` 一次，配合现有锁链声里的逐环金属声。
  - 收尾一记「落锁」声时闪一下柔光（`.igs-myth-flash.is-soft`），光带淡出。字卡「锁」。声音沿用 `myth-seal-chain`。
- **非人角色分支**（`creatureTarget` / `absorbCreatureSprite`，`fx-myth.js:215-229`、`fx-creature-battle.js:625-648`）：吸入动画和临时档案提示保留不改；吸入的目标点仍取各法器的位置（符咒取符纸处，金钵取光锥落点，葫芦取光源角，锁链取胸口）。
- 光带、地面光、光锥都要在 `life` 结束前淡出，节点随演出移除。

### 2.4 `pact` 血契印记（`fx-myth.js:289-297`，样式 `fx-myth-style.js:165-168`）
- 删：胸口两枚 SVG 圆环+三角的「印章」。
- 改为：在双方胸口位置各落一个**漫画印记**，复用新近加入的 `fx-symbols.js` 中 `MARK_SYMBOL_SVG.bondsigil`（ABO 终身标记用的漫画印记），换成暗红配色；落下时立绘 `jolt` 一次。
- 双方之间的红色连线（`drawLinks` 的 `line`）保留，但只走一次、不留常驻；字卡「血契」保留。声音沿用 `myth-pact`。

### 2.5 光色读正文（用户 10-24 要求）
- 法阵、结界、封印三类都新增一个可省的**光色**参数，由 AI 按正文描写填写（正文写「血色大阵」就填赤，写「青光结界」就填青）。复用现有 `MYTH_RELIC_TONES`（`fx-myth-model.js:31-34`：金/青/赤/红/紫/白/银/玉/绿）和现有色调 class `.is-gold/.is-azure/.is-crimson/.is-violet/.is-silver/.is-jade`（`fx-myth-style.js` 顶部，提供 `--myth-c/--myth-l`）。
- 标签格式（参数追加在末尾，旧写法不带光色仍然有效）：
  - `[igs-fx:formation|阵名|展开/入阵/破阵|光色]`
  - `[igs-fx:barrier|展开/破碎|光色]`
  - `[igs-fx:subdue|符咒/金钵/葫芦/锁链|目标|光色]`
  - 同步修改 `fx-myth-model.js` 里这三条的提示词说明（第 19、25、26 行附近），写明「光色取正文对光、阵、气的颜色描写，可写 金/青/赤/紫/白/玉，正文没写就省略」；解析处（第 58、64-69、82-89 行附近）用 `pick(MYTH_RELIC_TONES, …)` 读出。
- AI 没写光色时的兜底：在阵名（formation）里找颜色字（「血」「赤」「红」→ 赤，「青」「碧」→ 青，「紫」→ 紫，「玄」「黑」→ 紫偏暗，「玉」「翠」→ 玉，「白」「银」「雪」→ 白）；仍没有则用默认：法阵与封印暖金，结界青白，入阵紫。**不做本地正文词库扫描**，颜色判断交给 AI（用户规则：不要本地词库，提示词全开放）。
- 光色只走 CSS 变量：地面光、升光、光点、光带、光锥都用 `color-mix(in srgb, var(--myth-c) 70%, #fff4e0)` 降饱和后的颜色，不支持 `color-mix` 时回退 `var(--myth-c)`。赤色要再降一档，避免正红（0.4 节饱和度 ≤ 35%）。

### 2.6 提示词与模型
- 除 2.5 的光色参数外，`fx-myth-model.js` 的标签名、中文名称、动作参数不改。
- 若字卡文字改动（「封」「金钵」「收」「锁」），写成常量放在 `fx-myth.js` 顶部，便于以后调整。
