# 主角受众向计划（明星 / 邪教圣女 / mob 向 / 狂信徒向）

2026-11-07 起草，待用户拍板。本地文档，不推送。在 `STATS_RELATION_ROUND2_PLAN.md`（第二轮）之上做，新楼标记沿用 `strengthRev`，本计划改动只对 `strengthRev ≥ 2` 的楼生效。

## 背景

现有数值全是「具名角色对主角」的单向关系。主角是明星、教团圣女、被群体围绕的对象时，剧情的重心是**群体**（粉丝、信众、路人）与**少数极端个体**（狂信徒、私生饭、幕后操纵者），且常是不健康的题材。压测发现：

1. 群体没有位置：总则禁止为群体建档，但「信众对圣女的狂热」「粉丝对明星的风向」是剧情主轴，无处可记。
2. 多名无名者的亲密：亲密标签对象解析不了 → 整条丢弃，主角体力不扣。
3. 狂信徒、私生饭：好感、信任极高但不了解主角本人，关系名说不出「把主角当神 / 偶像」。
4. 压力顶满 100 后没有任何后果，mob 向与邪教题材很容易顶满。
5. 群体建档只靠提示词约束，AI 写了「村民们」「信众」仍会建出群体档案。

## 方案（每项标了建议，待拍板）

### 一、主角的「声望」条（建议做）

- 主角新增一条生活条 `fame`（0–100）。只有开了它的聊天才注入、才显示；同时最多开两条（如明星开「名气」+「粉丝狂热」，神明开「香火」+「恶名」）。
- 标签：`[igs-stat:fame|条名|上升/下降|小/中/大]`（只开一条时条名可省）。不写数字，按强度查表（小 2 / 中 5 / 大 10）。
- 群体仍不建档。声望是**主角的**一条，不是任何人的好感。
- **群体条（11-07 用户定）**：每条代表一个群体对主角的态度，条名自起（唯粉、CP粉、路人缘、黑粉……），性质从下表选；**同时最多 3 条**（取代上文「最多两条」）。
- **CP 粉多对**：CP 粉只占一条，条内按搭档分别记热度（`[igs-stat:fame|CP粉|搭档名|上升/下降|强度]`）。状态栏一条，展开看各对；提示词只注入热度最高的两对与本楼在场搭档那一对。CP 之间的此消彼长交给 AI 同时写两条标签，系统不自动联动。新增性质「组合热度」。
- **状态栏显示（11-07 用户定）**：设置里先选「状态栏显示声望」（默认关）；勾选后才出现下一级「显示细项」（默认关）。只开声望时状态栏显示一条汇总（如各群体条的名称与档位一行），开细项后每条群体条、CP 各对各自成条。主角栏与角色栏种类分开，群体条只属于主角。
- 粉丝群体之间的关系（唯粉撕 CP 粉、对家互掐）按「NPC 之间不碰」交给正文；具体大粉、黑粉头子照常单独建档。
- **性质预设表**（开条时选，决定条名、两端注入文案、每日自然变化、满格或归零时的强制事项）。代码只实现一套通用逻辑，加题材只加表项：

| 性质 | 谁在看 | 归零 | 满格 | 每日自然变化 |
|---|---|---|---|---|
| 名气 | 大众 | 过气 | 顶流 | 缓降 |
| 名誉 | 社会 | 声名狼藉 | 德高望重 | 无 |
| 恶名 | 敌人、平民 | 无人畏惧 | 闻风丧胆 | 无 |
| 信仰 | 信众 | 信众离散 | 被奉为神使 | 无 |
| 香火 | 信众（神力来源） | 神力衰竭、消散（强制事项写出虚弱、消散的迹象） | 神力鼎盛 | 每天减少 |
| 宠爱 | 君王、主人、金主 | 失宠 | 专宠 | 缓降 |
| 通缉 | 官府、追兵 | 安全 | 天罗地网 | 缓降 |
| 契约债务 | 恶魔、契约方 | 契约结清 | 被收走灵魂（满格是坏事） | 每天增加 |
| 民心 | 子民 | 起义、被推翻 | 万民归心 | 无 |
| 粉丝狂热 | 私生饭、狂信徒 | 理智追随 | 暴走（跟踪、围堵、献祭） | 缓降 |

- 各档注入文案按「有心事」式标准写常用说法，实施后派子代理筛措辞。

### 二、多名无名者的亲密（建议做，已在第二轮讨论里提出）

- 亲密标签的对象可写「群体」：只扣主角体力，不建档、不扣他人体力。
- 提示词亲密行补：「对象是无名者或多人时，角色名写群体。」

### 三、代码层拦群体建档（建议做）

- 登记角色时拦截明显的群体称呼：以「们、群、众」结尾，或在表里（村民、信众、信徒、粉丝、路人、众人、人群、大家、观众、教众……）。拦下记诊断 `stat-group-name`，标签丢弃。
- 用户手动登记、表格导入的不拦（用户确定要建的就建）。

### 四、「奉若神明」关系名（建议做）

- 条件：好感 >75、信任 >75、了解 ≤25；恋爱、友情、亲情三套共用；放在相知类之后、「情根深种」之前。
- 说明：「全心信奉，却并不了解真实的你」。
- 代价：暗恋、追星也会落到这条。在明星 / 圣女题材里这正是想要的结果，在普通恋爱里了解通常会随剧情升过 25，误伤有限。

### 五、压力满后转换（11-07 用户定：复用压力条变色，不加维度）

- **触发**：压力达到 100 且连续若干楼未降（具体楼数实施时定，默认 3），系统在提示词告知「已到极限」，并附压力主要来源（按最近上涨标签的类别统计）；由 AI 在合适时机写 `[igs-stat:break|状态名]`（主角）或 `[igs-stat:break|角色名|状态名]`（NPC）。不强制转换。
- **转换后**：同一条换色、换名，从 0 起计，表示新状态的深度；提示词改为「主角已堕落（程度：中）」一类。主角与 NPC 共用。
- **四类十个状态名（用户 11-07 定稿，暂不支持自定义）**：

| 类型 | 条的走向 | 状态名 |
|---|---|---|
| 沦陷 | 只涨不跌，满了二次转换（如「彻底堕落」） | 堕落、沉溺、同化 |
| 崩溃 | 慢慢回落，归零恢复为普通压力（治愈、救赎） | 破碎、疯狂、麻木 |
| 扭曲 | 不自然变化，只靠剧情推动 | 黑化、执念、封闭 |
| 蜕变 | 用一点少一点，用完退回普通压力 | 觉醒 |

- 来源提示：被迫、被支配 → 优先沦陷、扭曲；恐惧 → 崩溃、沦陷；失去、背叛 → 崩溃、扭曲；绝境 → 蜕变、崩溃。仅作提示，AI 按剧情选。
- 「顿悟」已是技能突破标签名，不作状态名。

### 五点五、其他条的定型（讨论稿，压测后再定，不全做）

| 条 | 定型 | 效果 |
|---|---|---|
| 芥蒂 100 | 宿仇 | 芥蒂不再自然消退 |
| 欲望 100 | 痴迷 | 注入「对主角念念不忘」；离开主角时压力上涨 |
| 信任 −100 | 永不原谅 | 信任上升标签无效，只能靠误会解除或重大事件 |
| 了解 100 | 看透 | 注入「主角的谎言与伪装瞒不过他」 |
| 体力长期透支 | 病倒 | 转为伤病状态 |

倾向只做芥蒂、欲望两项；其余视压测而定。

### 五点六、NPC 的体力与压力注入（11-07 用户定）

- NPC 的体力、压力一律参与结算并注入在场角色段（不再限于亲密消耗开启时）；状态栏默认不显示，设置加开关「显示角色的体力与压力」（默认关）。
- 注入写实际状态，不写元说明（定稿措辞）：
  - 体力低：林夏很疲惫，动作变慢，容易走神。
  - 体力 0：林夏体力耗尽，撑不住了，需要立刻休息。
  - 压力高：林夏有心事，睡不好，容易烦躁。
  - 压力极高：林夏神经紧绷到了极限，一点小事就可能失态。
- 数值正常时不写。

### 六、待定（不建议本轮做）

- **私生饭 / 跟踪者的恐惧感**：主角对某个人的恐惧无处记 → 用「我对TA」承载（第二轮 4.4），不另做数值。
- **群体内部派系**（保皇派、改革派信众）：属于群体之间的关系，按「NPC 之间不碰」不做。
- 主角堕落已由第五节压力转换承载。

## 压测场景（并入第二轮第七节脚本）

- 偶像明星：演出成功声望涨、丑闻曝光声望跌；私生饭（好感高、了解低）落到「奉若神明」；经纪人（具名、信任高）正常。
- 邪教圣女：信众狂热（声望 / 信仰涨）；大主教暗中操纵（好感中、信任低）；仪式中的群体亲密（只扣主角体力，压力顶满触发崩溃提示）。
- 狂信徒护卫：「狂热」算爱恋，好感满格、了解低 → 奉若神明；知道真相后了解上升 → 落回普通名字。

## 测试

- 声望标签三档；未开声望的聊天不注入、不结算。
- 亲密对象「群体」只扣主角体力，不建档。
- 群体称呼拦截；手动登记不拦。
- 奉若神明条件与排序。
- 压力 100 提示出现、回到 90 以下解除；旧楼不变。

## 补充：创伤瞬间拉满（11-07 用户定）

- 压力上升新增一档「极大」＝ +50，提示词限定只用于创伤性事件（被侵犯、目睹亲友死亡、遭到背叛等）；词表「极大」「巨大」「特大」改映射到极大。
- 角色卡勾选「脆弱」（与随身 / 无身体 / 亲人并列，traits.fragile）：压力上升 ×2。主角同样可勾。
- 压力转换补条件：单楼从 70 以下直接到 100 时当楼提示「已到极限」，不等连续 3 楼。
- 只对 strengthRev ≥ 2 生效。
- 标记自动评定（11-07 用户定）：角色建档 / 补全数值时，AI 按人设一并给出随身、无身体、亲人、脆弱与悟性档；人设明确写了才给，没写不给。结果直接勾在角色卡上，用户可改；用户手动改过的以手动为准，后续补全不覆盖。
