# 卡组生成参考素材

重建基础卡组、AI 新职业和职业升阶可以填写生成方向，并选择当前聊天的 MVU 变量与数据库技能／能力表作为参考。沿用原生成模板、校验、重试、账本与费用规则，不把素材里的数值直接导入战斗。

## 使用

人物状态 → 主角 → 卡组 → 重新生成基础卡组／转职（选新职业）／职业升阶。方向可留空；确认区展开「参考素材」，勾选变量分组和表，查看发送内容，或手填 `/主角/技能` 这样的 JSON 指针。键中斜杠写 `~1`，波浪号写 `~0`。

首次自动建档同样读取默认素材；首次失败后的主角手动重试与队友手动建档可调整来源。转职到已有职业不请求 AI，不展示方向输入。

只有明确归属目标角色或主角分支的资料默认选中。根级技能、无归属表等需手动勾选；不能自动识别的 MVU 结构可手填路径。来源冲突可指定 MVU 或技能表优先，仍由原协议限制卡牌张数、费用与效果。

读取失败、路径失效或素材超预算时阻止模型请求，可关闭失败来源继续。失败保留输入与旧卡组，成功或取消清除；来源选择只用于本次操作。关闭直接素材来源不会删除正文或世界书里原本已有的同类信息。

## 边界与模块归属

- `host/combat-generation-materials.js`：只读当前聊天，查找 MVU 或酒馆助手变量接口；最多向前读取40楼有效 `stat_data` 快照，再查聊天变量。兼容直接挂在楼层的旧版 `stat_data`；不读全局变量，不回写 MVU。
- `data/shujuku/combat-skill-materials.js`：识别技能／能力类表，按角色归属和掌握状态筛选，无归属表默认不选；不改写原表。
- `combat/generation-materials.js`：发现候选、解析 JSON 指针、选择与压缩素材；过滤敏感字段和原型链键。方向上限1600字符、素材序列化上限14000字符；深层、大数组和长字符串附截短／省略提示。
- `core/combat-material-context.js`：预览与确认共用读取入口；确认时重读，切聊天或选中资料消失时拒收。
- `visual/igs-ui/combat-generation-form.js`：嵌入原确认区，复用主题与按钮，不新增全局弹窗或持久化配置。中文输入不重绘，异步重绘保留焦点，取消／换角色／关闭拒收迟到预览。

提示与素材都是参考，不保证每个技能一对一成为卡牌。资料内的指令作为文本处理，不可改变输出协议。

## 卡组与职业反馈

卡组行显示当前属性换算后的效果、可展开的升级效果、X费规则、关键字与弃牌效果，复用 `scaleCard` 与 `combat-card-art`；实战仍受增益、减益和目标状态影响。标注基础／当前职业／个人／专属／其他已持有牌，数量为「卡组中／拥有」，所有档案文本转义。战斗只读保留，未解锁专属仍隐藏。

重建仍按3张基础攻击、3张基础防御、10张职业牌、4张个人牌重组；生成4–8张个人池不代表全部获得。只替换个人池与起始组，不覆盖生命、人物技能或个人被动。

转职保留已有卡组，新职业牌只进入候选池；升阶新增的3张职业牌也只入候选，职业被动按原规则增强。卡组页显示当前职业被动和可展开的未拥有职业池（包含升阶牌），不提供直接加入或生图按钮。职业池可以进入原升级奖励三选一；基础卡组重建仍仅抽普通／非普通职业牌，不能用它直接获取稀有／史诗升阶牌。

职业名称优先取已重放的当前职业，没有档案时才回落属性初始化名称；不改写 init，不重置六维、定位或偏好。

## 钱包读取恢复

数据库接口不可用时不缓存为成功；已注册聊天监听也须检查表版本并恢复读取。战斗侧数值表通道提供宿主实例和表版本，钱包读取先确认当前存档已加载。保持「战斗流水＋数值系统金钱」原余额口径，不迁移、不补钱、不回写余额。

## 验证

- 生成操作／界面行为16项：包含建档、重建、转职、升阶的素材传递、失败／取消／切聊天不扣费，输入保留、实时计数、六张个人池仅四张入组、效果展示，以及带初始化记录的转职和重读。
- 素材选择7项：角色归属、来源选择、路径、状态筛选、错误和预算限制。
- 钱包恢复2项及既有钱包／数值运行时定向回归。
- 构建与实际内嵌导入件冷启动、关闭、重启已分别验证；隔离 Chrome 390×844、1280×900检查表单和展开候选列表，无横向溢出。
