# 行为回归用例

本目录保留能发现实际故障的定向用例，不作为每次修改、构建或交付的全量门禁。

## 保留范围

- 正文解析、分页、指令归属与缓存失效。
- 设置持久化、历史格式兼容、导入导出和失败补偿。
- 异步取消、重复事件、资源释放与跨聊天隔离。
- 用户输入转义、URL/路径限制和凭据脱敏。
- 加载器版本锁定、启动失败恢复、实际 bundle 冷启动。
- 真实动作产生的状态变化和交互结果。
- Live2D 模型包安全校验、差分绑定往返、异步渲染释放与内嵌导入件启动。

## 已清理的检查

删除只验证源码写法、函数调用字符串、文件排布、固定 CSS 数值、视觉词汇的检查；同一行为用例混有此类断言时，只删除无价值部分。构建已经负责的文件存在性与格式检查不再重复维护。运行时的输入校验、权限控制、错误处理和构建完整性检查不受影响。

不按失败与否决定删留，也不把测试数量当作质量指标。不得为了让旧断言通过而修改正确的业务行为；历史失败仍需与当前契约核对，保留用例不表示已经全部通过。

翻页动作返回不代表合并渲染完成。验证实际页面时，使用 `helpers/reader-render.js` 的 `waitForReaderPage` 等待目标页快照，再断言正文、立绘、演出和 DOM；自动播放的虚拟时钟仍须单独推进。不要为同步断言关闭生产环境的翻页节流。监听器、定时器与阅读器使用 `t.after` 或 `finally` 清理，失败路径也必须释放。

## 使用方式

仅在问题需要时选定相关文件，例如在 `app/` 下执行：

```text
node --test tests/reader-floor-preparation.test.js
```

没有 `gate`、`structure`、`static`、`simulate`、`perf` 或批量 `test` npm 入口。不另建改名的全量运行器，不要求为每次改动补测试或凑覆盖率。视觉问题通过实际页面观察，源码字符串匹配不能证明视觉效果。

fake host / fixtures 的结果不等于真实酒馆、手机或真实 provider 验收。
