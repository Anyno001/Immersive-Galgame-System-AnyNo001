# igs-ui

本目录是 IGS 的 `Immersive Galgame System` 原版 UI 等价层。

## 边界

- 保留原版 `.igs-*` selector、`#igs-overlay`、`#igs-unified-settings`、旧 `igs_*` 存储键语义。
- 浏览器环境挂载真实 DOM；Node 模拟测试返回可断言的 snapshot/controller。
- 不在这里实现 scene 解析、preset registry 或 shujuku 业务逻辑；这里只负责阅读器和设置面板视图宿主。
- `embedded` 模式把唯一阅读器根挂到最新 AI 楼层 `.mes_text` 的兄弟容器，禁止把内部 DOM 插入 `.mes_text`。
- 内嵌上下轮只更换阅读源，挂载楼层保持最新 AI 消息；不得调用宿主跳楼。
- 内嵌模式的收纳与关闭按钮固定悬浮在阅读器右上角，保留 32px 透明点击区；全部工具 SVG 使用 11px 布局框并补偿 `viewBox` 留白，按钮间距为 1.5px、默认低透明度；不得使用工具条底色、描边、阴影或毛玻璃，也不得贴靠对话框或继承普通模式的顶部固定布局。
- 内嵌选项气泡必须约束在右上工具按钮与底部对话框之间；选项过多时只允许容器内部滚动，不得越出阅读器。
- 内嵌模式不显示“最新回复 / 前 N 轮 / 页数”等进度元数据行。
- 内嵌模式不渲染 IGS 输入框与发送按钮；选项“填入输入框”必须写入酒馆默认输入框，自动发送仍复用统一宿主发送链。
- 内嵌对话框必须完整约束在阅读器容器内：正文区域自行滚动，角色名和分割线不得收缩或被裁出可视范围；增加顶部留白时不得同步扩大左右与底部内边距。
- 内嵌容器桌面比例使用更修长的 `8:5`，移动端高度上限为 `min(74dvh, 680px)`；不得通过放大内部对话框代替容器增高。
- 默认对话框皮肤与全部选项使用霜夜微圆角平面语言；默认对话框无描边，选项仅允许极弱描边，透明度继续由现有玻璃浓度设置控制。
- 默认皮肤的 `readerSettings.dialogHeight` 在电脑浮窗、手机浮窗、楼层内嵌、网页全屏和浏览器全屏模式都作为对话框目标盒高，固定档包含 `60px`、`80px`、`120px` 及以上梯度，安全范围为 `60–600px`，超出当前阅读器可用高度时自动钳制；正文只在现有 `.igs-text` 内滚动，角色名、分隔线和输入区必须留在框内。`null` 恢复内容驱动的自适应高度，只保留随当前阅读器计算的安全上限，不得退回固定的 `220px/190px` CSS 上限。
- `readerSettings.dialogSkin` 只接受 `default` / `western-classic`；缺失或非法值回落 `default`。切换皮肤不得替换 `#igs-dialog`、`#igs-speaker`、`#igs-text`，不得换肤工具栏、选项、背景或正文解析。
- 西欧古典皮肤使用内嵌三片背景：高度 `184px`、左右端各 `110px` 保形、中段横向伸缩，常规最小目标宽度 `280px`；正文继续在现有安全区和滚动节点内排版。`readerSettings.classicDialogWidthPercent` 取 `60–100`，默认 `100`，只在电脑浮窗模式按阅读器可用宽度自动计算并居中；手机与楼层内嵌保持原有满宽。
- 西欧古典姓名牌复用 `#igs-speaker` 及其既有显隐条件；起点保持相对主框 `left:35px; top:-22px`，常规尺寸 `300×50px`，两端各 `40px`、中段占主要宽度，窄框只压缩中段。姓名使用 `13px` 深色字与细白描边并垂直居中；无姓名时不得出现空牌，切回默认必须恢复原姓名与分隔线布局。
- `readerSettings.classicVnTheme` 独立保存古典字体、颜色与对齐；`vnTheme` 保留默认皮肤设置，`fontSize` 共用。古典固定推荐高度时只禁用高度编辑、保留旧 `dialogHeight`；共享玻璃设置继续作用于工具栏、选项和数据库，不得为古典对话框全局关闭。
- 无背景图时固定使用霜夜底色 `#16181a`，不提供可配置色盘；历史 `emptyBackgroundColor` 存储字段必须兼容忽略并在下次保存时清除。
- 阅读器设置必须按「显示 / 选项 / 工具栏 / 主题」四个二级页面分组；切换只改变当前设置视图，不改写设置值。对话框风格与非默认风格参数必须放在「主题」页顶部独立大项，不得混入「显示」页常规几何参数行。
- 设置面板提供持久化的夜间/日间配色；日间色板以素白的 `#f1f1ef / #f7f7f5 / #fbfbfa / #e8e8e5` 层级为基准，只作用于 IGS 设置面板。
- 场景设置必须按「规则 / 素材」二级页面分组；素材页内继续保留「场景素材 / 角色立绘」切换。
- 场景条目的 `words` 在设置页作为场景别名管理；角色别名存于 `sceneAssets.characterAliases[主角色名]`。别名只参与名称归约，必须复用主条目的背景、情绪立绘和 `spriteLayouts` 位置键；角色改名/删除及场景预设保存、应用、导入、导出必须同步别名。
- 场景注入提示词输入只更新临时草稿，必须点击右侧「保存提示词」才覆盖持久规则；恢复默认键仍立即恢复并保存，界面必须显示保存状态。
- 「切换模式」分段按钮必须按模式数量动态等宽分配；内部 padding、图标间距、字号与图标尺寸必须随容器宽度收缩，不得用断点或固定 padding 挤压「楼层内嵌」标签。
- 设置主菜单「基础 / 正文替换 / 图像 / 场景 / 阅读器」必须使用五列等宽、文字居中的网格布局。
- 「阅读器 → 显示」页最底部提供左上角状态栏总开关；关闭时不挂载状态栏、不读取数据库、不注册表格更新回调，子设置值保留；开启后才显示大小（小/中/大）、读取表格多选、显示情绪标签、头像圆角、状态栏背景与 HUD 条配色。默认：关闭、中、情绪开、圆形、无背景、彩色、未选表。
- 状态栏不显示角色名或表名；角色名仅用于主名/别名归约、头像查找与表格行匹配。情绪标签取当前 `[igs-char:]`/`[igs-thought:]` 的原始情绪值，不得使用已归约的 `spriteMood`；旁白不继承上一句情绪。胶囊无描边、半透明、单行省略。
- 状态栏头像使用独立映射 `sceneAssets.statusAvatars[主角色名]`，不占用情绪立绘槽；在角色卡的「角色别名」与情绪立绘之间提供上传/替换/清除，别名复用主角色头像，角色改名迁移、删除清理，场景预设保存/应用/导入/导出必须同步。未上传时使用内置透明 SVG 小人。圆角固定六档：方角 `0px`、微圆角 `6px`、小圆角 `10px`、中圆角 `16px`、大圆角 `24px`、圆形 `50%`。
- 状态栏表格选择保存 `{uid,name}` 并保留选择顺序；空选不扫描任何表。数值识别支持 `%`、`当前值/上限` 与单元格内分号多指标，排除日期与时间样式；显式百分比超出 `0–100` 判为非法不显示。读取失败、缺表、缺行不得显示成 `0%`。
- 右侧 HUD 最多显示四条，顺序为所选表顺序再到表内字段顺序，超出部分以 `+N` 提示且不占第五行；一至四条在身份区高度内均匀分布。大小档在响应式倍率（小 `0.86`、中 `1.00`、大 `1.16`）计算完成后统一乘 `0.8`，并同步缩放头像、圆角、间距、胶囊、文字、进度条与折叠控件。
- HUD 条配色仅允许 `彩色` 与 `灰白`；默认彩色并保留信任、好感、了解及稳定色槽，灰白统一使用中性渐变，不改变数值、排序、轨道或标签。
- 状态栏背景仅两种：`无背景` 不绘制底板；`跟随对话框` 使用默认对话框背景色的 `50%` 透明混合，复用对话框模糊并使用更小的 `6px` 缩放圆角，不新增独立透明度字段。状态栏不拦截点击（`pointer-events:none`），选项气泡显示时抑制，顶部固定工具栏时下移，楼层内嵌避开右上工具按钮。
- 首版只为默认皮肤建立状态栏视觉契约；不得修改西欧古典对话框资产、固定高度与姓名牌契约。
- 内嵌模式只对最新 AI 楼层的 `.mes_text` 做 `display:none !important` 视觉隐藏；不得删除、替换或清空该节点及其文本，关闭或换楼层时必须恢复原始显示值和优先级。
- IGS 阅读器、设置页和数据库面板的所有滚动区域保留滚动能力，但不得显示原生滚动条。
- 流式观察只在内嵌阅读器打开时启用；生成期间必须持续隐藏最新 AI 楼层原文并只显示载入态，宿主结束事件后一次性解析，结束后的普通 DOM 更新不得重新点亮动画。
- 当前消息不存在任何 `[igs-scene:]`、`[igs-char:]`、`[igs-thought:]` 指令时，所有文段必须强制按旁白分类，禁止根据文本外形猜测台词或心理话。
- `[igs-scene:]`、`[igs-char:]`、`[igs-thought:]` 与旁白写在同一段时，必须以指令闭合 `]` 为分界断行：`]` 之后的文本属于旁白，不得被并入台词或心理话正文，也不得进入气泡。

## 硬约束

- 不得用新的 `.igs-*` DOM 替换原版 `.igs-*` DOM。
- `openSettings()` 不得再返回 `settings-ui-not-mounted`。
- `openLatestAvailable()` / `openViewerFromMessage()` 必须能得到 `#igs-overlay` 等价结构。
- 同一时刻最多存在一个 `[data-igs-embedded-host="1"]` 和一个 `#igs-overlay`；关闭、切模式和销毁必须恢复宿主原文。
- 普通翻页必须复用已准备的正文解析结果，不得无条件重跑整楼正文管线。
- 修改模板、样式和字段路径前，先对照 `projects/Immersive Galgame System 原版备份/tavern helper/bridge/src/ui/**` 与 `app/fixtures/igs-ui/*`。
