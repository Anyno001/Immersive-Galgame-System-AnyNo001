# igs-ui

本目录是 IGS 的 `Immersive Galgame System` 原版 UI 等价层。

## 边界

- 保留原版 `.igs-*` selector、`#igs-overlay`、`#igs-unified-settings`、旧 `igs_*` 存储键语义。
- 浏览器环境挂载真实 DOM；Node 模拟测试返回可断言的 snapshot/controller。
- 不在这里实现 scene 解析、preset registry 或 shujuku 业务逻辑；这里只负责阅读器和设置面板视图宿主。
- `embedded` 模式把唯一阅读器根挂到最新 AI 楼层 `.mes_text` 的兄弟容器，禁止把内部 DOM 插入 `.mes_text`。
- 内嵌上下轮只更换阅读源，挂载楼层保持最新 AI 消息；不得调用宿主跳楼。
- 默认皮肤全部阅读模式的收纳与关闭按钮固定悬浮在阅读器右上角，保留 32px 透明点击区；全部工具 SVG 使用 11px 布局框并补偿 `viewBox` 留白，按钮间距为 1.5px、默认低透明度；不得使用工具条底色、描边、阴影或毛玻璃，也不得贴靠对话框。西欧古典皮肤保持原工具栏停靠语义。
- 内嵌选项气泡必须约束在右上工具按钮与底部对话框之间；选项过多时只允许容器内部滚动，不得越出阅读器。
- 对话框内 `#igs-progress` 的“当前页/总页数、图位”等进度元数据是行内状态栏；五种阅读模式（含楼层内嵌）都由 `showStatusLine` 开关控制，默认关闭，开启时显示当前页数，关闭时不显示、不占位。不得再在底部重复渲染页数。
- 内嵌模式不渲染 IGS 输入框与发送按钮；选项“填入输入框”必须写入酒馆默认输入框，自动发送仍复用统一宿主发送链。
- 内嵌对话框必须完整约束在阅读器容器内：正文区域自行滚动，角色名和分割线不得收缩或被裁出可视范围；增加顶部留白时不得同步扩大左右与底部内边距。
- 内嵌容器桌面比例使用更修长的 `8:5`，移动端高度上限为 `min(74dvh, 680px)`；不得通过放大内部对话框代替容器增高。
- 默认对话框皮肤与全部选项使用霜夜微圆角平面语言；默认对话框无描边，选项仅允许极弱描边，透明度继续由现有玻璃浓度设置控制。
- 默认皮肤的 `readerSettings.dialogHeight` 在电脑浮窗、手机浮窗、楼层内嵌、网页全屏和浏览器全屏模式统一表示插件 iframe 高度比例，档位为 `5% / 8% / 12% / 15% / 18% / 20% / 25% / 30% / 35% / 40%`。自动 loader 必须把源插件 iframe 的高度桥接给父页 bundle，禁止误用酒馆父窗口高度；打开阅读器、切换模式或修改档位时计算一次像素盒高并冻结，同一阅读器实例内的台词长短、分页、流式更新及宿主后续 resize 不得改变该值。历史 `60–600` px 值仅兼容读取并保持原像素高度，改选新档位后保存为比例。正文只在现有 `.igs-text` 内滚动，角色名、分隔线和输入区必须留在框内。`null` 恢复内容驱动的自适应高度及当前模式安全上限。
- `readerSettings.dialogSkin` 只接受 `default` / `western-classic` / `plant-coffee` / `black-white-manga` / `cute-pink` / `gradient-veil`；缺失或非法值回落 `default`。切换皮肤不得替换 `#igs-dialog`、`#igs-speaker`、`#igs-text`，不得换肤工具栏、选项、背景或正文解析。
- `readerSettings.dialogSkin=gradient-veil` 为第三种可选皮肤：共享默认 `vnTheme`、布局、正文与交互配置，仅新增 `readerSettings.gradientVeil` 的颜色、stage 高度比例、最大不透明度和姓名样式；黑幕使用全宽 `to top` 渐变贴合阅读器左右与底边，不使用毛玻璃，不把渐变写入纯色 `--igs-dialog-bg`。
- 渐变黑幕的姓名样式默认沿用默认主题，可选 `plain-text`；切回 `default` 或 `western-classic` 必须清除黑幕节点显示、专属变量和姓名样式状态，西欧古典主题与姓名牌资产保持隔离。
- 三套素材主题共享默认 `vnTheme` 与交互链，分别使用项目内 PNG 三片资源：植物咖啡 `130/898/130 × 177`、黑白漫画 `90/930/89 × 191`、超可爱粉 `120/913/145 × 215`；各自姓名框保留原作者切片比例，不互用西欧古典几何。
- 三片素材（含西欧古典）预先横向拼成单张 `dialog.png` / `name.png`，以 `border-image … fill` 一次绘制、高度随框拉伸；禁止拆成三层背景分别定位（缩放后各层独立取整会漏缝，半透明纸面重叠会叠出亮线）。
- 日间简约、优雅欧式为通栏主题（`buildDialogFrameCss` 的 `flush`），全部阅读模式贴合阅读器左右与底边、与阅读器等宽；其余主题保持卡片边距。优雅欧式底板取作者 `frame_message` 左右两片拼成（两端 200px 渐隐线保形、中段拉伸），中央饰纹由原图反合成抠出、按原尺寸单独叠放，不随宽度拉伸。
- 复古日式、冒险旅途同为三片素材主题（裁自作者素材库 `messgeframe_01`/`text_ribbon_06`、`message_frame_02_light`/`name_tag_02`）；复古日式在 `max-width:640px` 下切换 `compact` 几何，避免两侧花簇挤占正文。
- 日间简约、温暖绘本、优雅欧式、魔法学院为纯 CSS 主题（`dialog-theme-css-skins.js`），与三片主题共用 `dialog-skin-frame.js` 骨架并计入 `ILLUSTRATED_DIALOG_SKINS`；优雅欧式内嵌一列黑纱底板与两枚饰纹 PNG，照作者三切片拼法：饰纹（含穿过它的线段）居中不动，两侧细线用渐变向外延伸、两端渐隐，细线不得穿过饰纹（否则会填满花纹间隙）。魔法学院的角花、星点与徽带全用渐变绘制，无素材。温暖绘本的断开外描边依赖 `overflow-clip-margin`，不支持时只丢描边。
- 选项跟随皮肤：西欧古典、植物咖啡、黑白漫画、超可爱粉、复古日式、冒险旅途使用作者选项按钮 PNG 的 `border-image` 九宫格（`choice`/`choice-hover`/`choice-active`），其余主题为 CSS。
- 状态栏 HUD 与情绪标签跟随皮肤（`dialog-theme-hud.js`）：各主题分别定义面板、情绪标签、头像描边与角标、兜底头像、HUD 条轨道与填充；填充颜色经 `--igs-hud-fill-color` 传入，灰白模式改用主题的 `--igs-hud-fill-neutral`。复古日式、冒险旅途的情绪标签用作者缎带/名牌 PNG（`tag.png`）。资料小菜单（箭头与四个入口）不随皮肤变化。
- 素材/CSS 主题几何（框高、两端宽、姓名牌、正文内距、装饰伪元素）统一写成 `calc(Npx * var(--igs-skin-scale,1))`；`readerSettings.skinDialogScale` 取 `1/0.9/0.8/0.7/0.6`（默认 `1`），由渲染层写到 `#igs-overlay`。字号与文字光晕不参与缩放。正文直接压在花纹上排版，各主题用同底色光晕描边保证可读，不再为避让装饰内缩。主题不再强制字体，排版默认值只含颜色与对齐。
- 复古日式、冒险旅途同为三片素材主题（裁自作者素材库 `messgeframe_01`/`text_ribbon_06`、`message_frame_02_light`/`name_tag_02`）；复古日式在 `max-width:640px` 下切换 `compact` 几何，避免两侧花簇挤占正文。
- 日间简约、温暖绘本、优雅欧式、魔法学院为纯 CSS 主题（`dialog-theme-css-skins.js`），与三片主题共用 `dialog-skin-frame.js` 骨架并计入 `ILLUSTRATED_DIALOG_SKINS`；优雅欧式内嵌一列黑纱底板与两枚饰纹 PNG，照作者三切片拼法：饰纹（含穿过它的线段）居中不动，两侧细线用渐变向外延伸、两端渐隐，细线不得穿过饰纹（否则会填满花纹间隙）。魔法学院的角花、星点与徽带全用渐变绘制，无素材。温暖绘本的断开外描边依赖 `overflow-clip-margin`，不支持时只丢描边。
- 选项跟随皮肤：西欧古典、植物咖啡、黑白漫画、超可爱粉、复古日式、冒险旅途使用作者选项按钮 PNG 的 `border-image` 九宫格（`choice`/`choice-hover`/`choice-active`），其余主题为 CSS。
- 西欧古典皮肤使用内嵌三片背景：高度 `184px`、左右端各 `110px` 保形、中段横向伸缩，常规最小目标宽度 `280px`；正文继续在现有安全区和滚动节点内排版。`readerSettings.classicDialogWidthPercent` 取 `60–100`，默认 `100`，只在电脑浮窗模式按阅读器可用宽度自动计算并居中；手机与楼层内嵌保持原有满宽。
- 西欧古典姓名牌复用 `#igs-speaker` 及其既有显隐条件；常规起点相对主框为 `left:35px; top:-22px`，常规尺寸 `300×50px`，两端各 `40px`、中段占主要宽度。窄屏视口（`max-width:640px`）的五种阅读模式统一使用相对主框 `41.667%` 宽度、`left:38px; top:-14px` 与原始 `50px` 高度；姓名使用 `13px` 深色字与细白描边并垂直居中。无姓名时不得出现空牌，切回默认必须恢复原姓名与分隔线布局。
- `readerSettings.classicVnTheme` 独立保存古典字体、颜色与对齐；`vnTheme` 保留默认皮肤设置，`fontSize` 共用。古典固定推荐高度时只禁用高度编辑、保留旧 `dialogHeight`；共享玻璃设置继续作用于工具栏、选项和数据库，不得为古典对话框全局关闭。
- 「阅读器 → 对话框」页按「风格 → 尺寸 → 背景」展示；渐变黑幕专属参数紧随皮肤选择，西欧古典电脑端宽度紧随对话框宽度。文字字号、字重与各类文字主题放在独立的「文字」页，展示重排不改变字段路径、皮肤条件或保存语义；皮肤选择仍保存到 `readerSettings.dialogSkin`。
- 台词字体统一由当前主题的 `textFont` 控制：默认/素材主题使用 `readerSettings.vnTheme.textFont`，西欧古典使用 `readerSettings.classicVnTheme.textFont`；历史 `readerSettings.dialogFont` 读取时迁移到两套主题的 `textFont`，不再作为全局覆盖项。`dialogFontWeight` 默认 `null`，仅控制姓名和正文，不影响工具栏、输入框、选项气泡、设置页；支持细体 / 常规 / 中等 / 粗体，非法与旧数据缺失值回到跟随皮肤。西欧古典的宽高控件不再附带「去主题页」或「固定184px」说明。原有分类字体选项也可单独选用内置有爱圆体，其余字体与皮肤默认不变。
- 「阅读器 → 文字 → 排版」的 `dialogTextEffect` 为 `off`（默认）/`outline`（硬描边）/`shadow`（投影式）；同一行的增强颜色、浓淡、大小分别为 `dialogTextEffectColor`（默认 `#000000`）、`dialogTextEffectStrength`（默认 20%，5–50%）、`dialogTextEffectSize`（默认 0.8px，可选 0.4–2px），两种效果共用。描边先画后以原文字填充覆盖内侧，投影绘制于字形后；只作用于当前对话框正文 `#igs-text`，不作用于姓名、工具栏、选项或设置页；关闭时移除内联效果，恢复皮肤原有样式。非法颜色、模式和大小回到默认值。
- 无背景图时固定使用霜夜底色 `#16181a`，不提供可配置色盘；历史 `emptyBackgroundColor` 存储字段必须兼容忽略并在下次保存时清除。
- 阅读器设置必须按「对话框 / 文字 / 演出 / 界面」四个二级页面分组；切换只改变当前设置视图，不改写设置值。「对话框」承载皮肤、尺寸与背景；「文字」承载字号、字重与角色名、台词、旁白、心里话、分隔线的主题设置；「演出」按打字机、震动、漫画演出（整合卡：通用风格 / 情绪特效〔情绪符号与集中线、心跳、闪白〕/ 剧情提示〔标题卡、数值提示、标签演出〕/ 音效）、舞台调度、文字演出、日常演出、场景声音、线上交流、天气、场景演出排列；「界面」承载背景图、状态栏、选项气泡与工具栏。重分类只移动展示位置，不得改写既有持久化路径。
- 设置面板提供持久化的四种配色：`地雷色`（默认）、`奶油风`、`浅色`、`深色`；四套配色只作用于 IGS 设置面板，均保留毛玻璃遮罩、水波纹材质、浏览器不支持毛玻璃时的实心回退和 `prefers-reduced-transparency` 降级。历史 `night` / `day` 值读取时分别兼容迁移为 `landmine` / `cream`，新保存值使用四主题内部值。
- 天气演出（`readerSettings.weatherFx`，默认关闭）由 `weather-fx-runtime.js` 按当前 `[igs-scene:地点|时间|天气]` 解析出类型（雨/雪/雾/沙尘/风/阴/晴，按序先命中者为主）、程度、雷与风修饰、室内外与五时段，只写 `#igs-effect-layer`（背景之上、立绘之下）与 `#igs-effect-front-layer`（立绘之上、对话层之下）的 `data-igs-weather-fx-*` 属性；程度由 `resolveWeatherFxGrade` 细分为 `drizzle / light / medium / heavy / storm`（毛毛雨、小雨、中雨、大雨、暴雨，重词先于轻词判定），方案同时带旧三档 `level`（由细分档折算，与细分前判定一致，场景音频等旧消费方继续用 `level`）；粒子密度/速度/雨丝长度、天气调色幅度、地图光照与暴雨闪电间隔按 `grade` 取值，调用方不得另写程度词表；样式集中在 `weather-fx-style.js`，时段只提供色彩与光源方位变量。室内外按地点末尾命中词判定（室内词与 `outdoorWords` 均可在设置编辑），室内不得出现雨雪粒子，只保留压暗、窗面水痕、窗光尘埃与闪电侧光，室内风不演出。雨/雪/风/沙尘室外粒子由 `weather-fx-particles.js` 的双画布承担，必须锁 30fps、按 CSS 像素绘制、合批、图层隐藏时停帧、脱离文档时自退；减少动态效果时只保留静态调色。
- 舞台暂停（`stage-pause.js`）：每个 `#igs-overlay` 维护暂停原因集合，任一成立即暂停，overlay 挂 `data-igs-paused`（值为原因列表），全部解除后移除并通知 `onStageResume` 订阅者。原因：`hidden`（页面隐藏）、`offscreen`（仅内嵌模式，IntersectionObserver 观察阅读器根）、`panel:settings` / `panel:record` / `panel:map` / `panel:gallery`（盖住舞台的面板打开期间）。`openReader` 起驱动、`closeReader` 解绑。CSS 只对舞台层（背景、立绘、多人立绘、天气双层、演出双层、日常天空层、调色层、亲密演出后层、舞台指示残影与幕布）及其子元素和伪元素设 `animation-play-state:paused`；对话层（打字机、点击等待）、工具栏、资料页 / 地图 / CG 库与设置面板不暂停，WAAPI 动画与计时器不受影响。常驻粒子循环（天气粒子、花瓣落叶）暂停时不排帧、恢复后重新拉起；烟花与孔明灯是带音效与计时的一次性演出，不暂停。面板内的画布（如地图天气层）不属于舞台，不受暂停影响。
- 画质档（`render-quality.js`，`readerSettings.performance.quality`：`auto` / `normal` / `low`，缺失或非法值视为 `auto`；不属于一键演出档位）：`auto` 在 `navigator.deviceMemory <= 4`、或 `hardwareConcurrency <= 4` 且为粗指针触屏、或 `prefers-reduced-motion` 时判为低画质。每次渲染由 `applyReaderSnapshotToDom` 先于天气与日常演出写入：低画质时 `#igs-overlay` 挂 `data-igs-quality="low"`，否则移除该属性。低画质的 CSS 集中在 `stage-direction-style.js`：停推镜与立绘呼吸（含亲密演出呼吸），亲密演出背景不再模糊并隐藏 `#igs-bg-blur`，梦境雾去 blur；滤镜层与 bokeh 由 `scene-grade.js` / `romance-style.js` 各自处理。粒子模块读取 `getQualityFactor()`（低画质 `{ density: .5, fps: 20, dprCap: 1 }`，标准 `{ density: 1, fps: null, dprCap: null }` 即沿用模块默认值）：天气粒子、花瓣数量减半，烟花每朵火花数与孔明灯数量减半，帧率 20，烟花与孔明灯 dprCap 由 2 降为 1；天气与花瓣在运行中察觉档位变化会重新布点。标准档的画质参数（密度、帧率、dprCap）与改动前一致。设置入口：首页演出档位条与「阅读器 › 演出」一键档位卡片内的「画质」下拉（`render-quality-fields.js`）。
- 场景设置必须按「规则 / 素材」二级页面分组；素材页内继续保留「场景素材 / 角色立绘」切换。
- 场景条目的 `words` 在设置页作为场景别名管理；角色别名存于 `sceneAssets.characterAliases[主角色名]`。别名只参与名称归约，必须复用主条目的背景、情绪立绘和 `spriteLayouts` 位置键；角色改名/删除及场景预设保存、应用、导入、导出必须同步别名。

- 环境滤镜（`scene-grade.js`）：时段调色由 `readerSettings.timeTint`（设置页称「环境滤镜」，含强度）控制；子开关 `timeTint.night`（「夜间调色」，缺省视为开启，旧存档行为不变）关闭时夜晚与深夜不做时段调色，清晨、黄昏与天气调色照常；天气调色跟随 `weatherFx.enabled`，没有单独开关；两者任一开启即运行。由渲染层 `applySceneGrade` 直接调用，不依附舞台调度。背景与立绘的 `filter` 一律由样式表按变量合成：`#igs-bg` = `brightness(--igs-bg-brightness)` + `--igs-grade-bg`；`#igs-sprite`、`.igs-sd-sprite-ghost` = `--igs-sprite-dim`（旁白压暗，由 `.igs-sprite-narration` 写入）+ `--igs-grade-sprite`；`#igs-cast` 整层吃 `--igs-grade-sprite`。两个调色变量只写在上述消费元素（及 `#igs-bg-blur`）上，不写 overlay 根，避免渐变每帧整棵子树重算样式；渐变结束后才出现的立绘 / 多人层在下次 render 时补写。`#igs-bg-blur` 默认 `display:none`（不透明的 `#igs-bg` 本就完全盖住它），只在亲密演出给背景加模糊（`[data-igs-rm-glow]` 且非回忆 / 梦境）时显示。任何模块不得再给 `#igs-bg` / `#igs-sprite` 写行内 `filter`。调色层 `.igs-grade-layer`（A/B 两层交替淡入）插在 `#igs-bg` 与 `#igs-sprite` 之间，只染背景；立绘色偏用 `<svg class="igs-grade-defs">` 内每个阅读器独立 id 的 `feColorMatrix`，调色幅度为背景的 0.55。参数在 1.4s 内由 JS 插值，减少动态效果时直接跳到终值；天气演出开启时，`igs-weather-flash` 会让背景与立绘同步提亮后回落。回忆、梦境期间完全让位（叙事滤镜的 `!important` 覆盖，调色层透明）；亲密演出的背景规则同样带 `!important`，期间暂时覆盖背景调色。低画质档（`#igs-overlay[data-igs-quality="low"]`）不用混合模式：调色层改为普通叠色 `--igs-grade-flat`（`paintLayers` 按 `flatGradeTint` 对正片叠底颜色做最小二乘逼近后写在每层上），`::after` 高光不渲染。关闭阅读器调用 `cancelSceneGrade`。调参试看页：`app/fixtures/filter-lab/`。
- 「素材 → 角色」的 `bridge.sceneAssets.spriteEnhance` 默认关闭；复用「统一角色立绘位置」的开关样式，开启后才显示硬描边／投影式及颜色、浓淡、大小，并提示可能增加性能开销。效果沿透明立绘轮廓以 `drop-shadow` 绘制：单人追加在旁白压暗与环境调色滤镜之后（包括内嵌旁白），多人陪衬追加在各自原有明暗滤镜之后；关闭、无图或编辑立绘时清除效果。硬描边使用四方向阴影，手机性能须实机验证。
- 舞台调度（`stage-direction-*.js`）包含 `readerSettings.sceneTransition / timeTint / spriteMotion / spriteActions / camera`，全部默认关闭，归入「演出 → 舞台调度」。转场只在背景或立绘地址变化时播放、首次渲染不播：旧图复制为紧贴 `#igs-bg` / `#igs-sprite` 之后的残影层，新图 `decode()`（上限 1.5s）后残影按淡入/横擦/圈入/百叶窗退场；黑场用 z-index 3 幕布，峰值时移除旧图、新立绘随幕布升起登场；同一地点只换时段总是淡入；同角色换表情为 220ms 残影淡出。立绘动作与说话轻弹只在翻到新页时按原始 `content.statusEmotion` 中文精确匹配播放一次，以 Web Animations `composite:'add'` 叠加在呼吸 CSS 动画之上；NSFW、聊天页、卡片页不触发。镜头只用独立 `translate` / `scale` 属性（视差仅鼠标指针、特写 1.12 倍），不得写立绘 inline `transform`；两者由 CSS 变量合成（特写 `--igs-sd-closeup-scale`、视差 `--igs-sd-tx/ty`、亲密演出 `--igs-rm-scale/dx`，总放大上限 1.3），任何模块不得直接写死立绘 `scale` / `translate`。视差变量 `--igs-sd-px/py` 只写在 `#igs-bg`、`#igs-sprite`、`#igs-cast` 上，舞台 rect 缓存到 ResizeObserver / resize / scroll 时失效，更新经 rAF 合并。时段调色已并入「环境滤镜」（`scene-grade.js`），不再由舞台调度渲染。减少动态效果时保留淡入与调色，取消呼吸、动作、推镜、特写、冲击推近与视差；关闭阅读器调用 `cancelStageDirection`。镜头冲击推近（`camera-impact.js`；`camera.impact` 默认关闭，旧设置不会自动开启；触发词 `camera.impactEmotions`）：只在翻到新页时按原始 `content.statusEmotion` 中文精确匹配，在 `#igs-stage-motion` 上用独立 `scale` 的 Web Animation 推近到 1.045 倍再回弹（420ms），与舞台震动的 `transform` 动画叠加、互不覆盖，不写立绘 `scale` / `translate`；同页重绘不重播；冲击音由 `chat-sfx.playSynthPartials` 合成进 sfx 总线，与镜头同时起播，受 `readerSettings.fxSound` 开关与音量控制（`ctx.playSfx` 可注入替换）；NSFW、聊天页、卡片页、立绘编辑中、低画质档（`data-igs-quality="low"`）不触发；同页演出预算：本页舞台震动已在播放（渲染层传入 `ctx.stageShakeActive`）时冲击推近让位，只记 `camera:impact-yield`，特写不受影响；时长与缓动取自 `fx-rhythm.js` 的 `FX_RHYTHM.impact`；`cancelStageDirection` 同时取消冲击动画与音效。演出节奏规格（`fx-rhythm.js`）：`impact` 420ms / `enter` 600ms / `ambient` 1200ms 的命名时长与缓动，新演出优先取用，既有模块迁移时必须保持原时长与缓动不变。
- 多角色同屏（`stage-cast-render.js`，`readerSettings.stageCast.enabled`，默认关闭，不进一键演出档位）：`#igs-sprite` 永远是说话人；`#igs-cast` 位于 `#igs-sprite` 之前、同为 z-index 2，只放陪衬、压暗、不接情绪动作/特写/亲密演出；`spriteMotion.enabled` 开启时陪衬可呼吸、可朝向说话人（第二批）：`spriteMotion.castBreathing`（默认开）由舞台调度在根节点写 `data-igs-cast-breathe`，周期与延迟由 `castBreathePhase` 按角色名确定性哈希（4.8～5.8s / 0～2s，写成元素变量 `--igs-cast-breathe` / `--igs-cast-delay`，原点 `--igs-cast-origin-x` 取槽位 posX），低画质、减少动效与立绘编辑时不播；`spriteMotion.castLean`（默认开）用独立属性 `rotate` ±0.8deg（`castLeanOf`，脚底为原点）朝说话人微倾，旁白页（无说话人槽位）保持上一页朝向，暧昧退场（recede）与减少动效时由渲染层传 `lean:null` 回正，头部对齐后的补刷新不清朝向；陪衬滑入 / 滑出的位移动画用 `composite:'add'` 叠在呼吸上；陪衬反应 `stageCast.castReact`（默认关，第三批）：`[igs-fx:react|角色|情绪]` 由 `scene/fx-directives.js` 独立分支解析为 `fx.reacts`（不进入 `FX_TAG_KINDS` 与演出标签开关，每页最多 3 条，缺角色整条丢弃，角色写「全员」作用于全部在台陪衬），提示词只在 `stageCast.enabled && castReact` 时经 `resolveStageCastFxPromptRule`（整块注入）与 `stageCastGrammarLines`（按需注入）出现；`planCastReacts` 按漫画符号词表与动作词表映射情绪词（都中两者都播、都不中只小跳，说话人情绪命中 surprise 词表时无动作的陪衬全员小跳），只读词表、不看 `mangaFx` / `spriteActions` 总开关；`findCalledCast` 对本页正文做 2 字以上名字 / 别名点名，命中的陪衬用 `CAST_CALLED_FRAME`（修罗场对象的 focus 优先）；陪衬动作经 `playCastBeats` 挂在 `_igsCastBeat`，换页、下台、清层时取消（sink 的 `fill:'forwards'` 不残留），同页重绘不重播；陪衬符号经 `applyFxToDom({ cast, castMarks })` 落在该陪衬头部，不依赖漫画演出总开关，每页只播一次，目标不在台上或无图时丢弃；多人时横向位置由槽位决定，scale / posY 仍取各角色布局；退回单人条件见 `isCastCollapsed`，聊天演出页由宿主不产出名单。舞台调度通过 `ctx.castKeys` 把同屏角色间的说话人切换当作换表情处理（只做残影淡出）。
- 多角色同屏动画（`stage-cast-motion.js`）：陪衬层按角色名对比前后两次名单，新上台从近侧滑入、换槽位平移、下台往近侧滑出；说话人交接时旧说话人在陪衬层由亮转暗、新说话人在 `#igs-sprite` 由暗转亮并从旧位置平移；新人直接开口时 `#igs-sprite` 从近侧滑入（舞台调度已播登场则跳过）。入场 / 挪位 / 交接动画用 `fill:'backwards'`，不得用 `forwards` 以免覆盖后续内联样式。头部对齐（`stageCast.alignHeads`，默认开）以本场景最早开口的在场者为参照，头宽缩放限制 0.8～1.25 倍，头顶同高；探测未就绪时先不对齐，探测完成后只重排立绘样式；新上台的陪衬经 `applyCastToDom({ ready })` 等对齐重排完成再滑入（上限 `CAST_ALIGN_WAIT_MS`，超时照常滑入），已在台上的成员不等。减弱动效时只淡入淡出。
- 多角色同屏补齐：多人时「立绘编辑」进入槽位编辑（`cast-slot-edit.js`，`current.spriteEditMode.kind === 'cast'`），每人按 `模式::人数::槽位::身份` 存到 `readerSettings.castSlotLayouts`，与单人 `spriteLayouts` 分开；有槽位位置的人不参与头部对齐调整。槽位编辑期间渲染层不改陪衬层与说话人布局。拍照把陪衬层（不压暗）画在说话人之前。战斗不再退回单人，出招目标优先级为主角 → 说话人 → 陪衬（`targetKind:'cast'` + `targetChar`）→ 有立绘的对手 → 舞台；说话人与陪衬目标先按名字直接匹配，再经 `planBattleFx({ keyOf })`（渲染层传 `castKeyOfSnapshot`，与同屏名单同源）把别名归一到主名比对。
- 陪衬反应（第三批，`readerSettings.stageCast.castReact`，默认关，只在 `stageCast.enabled` 时生效）：`[igs-fx:react|角色|情绪]` 由 `scene/fx-directives.js` 独立分支解析为 `fx.reacts`（每页最多 `FX_REACT_PAGE_MAX = 3` 条，缺角色名整条丢弃，「全员」指全部陪衬），不进入 `FX_TAG_KINDS`、`instants` 与演出标签开关；提示词由 `resolveStageCastFxPromptRule`（旧拼接路径）与 `stageCastGrammarLines`（`tag-grammar` 按需路径）注入，两开关同时开启才出现。`planCastReacts` 只读规范化后的 `mangaFx.symbols` 与 `spriteActions` 词表（不看它们的总开关）：情绪词同时命中符号与动作时两者都播，都不中只小跳，目标不在台上丢弃，说话人情绪命中 surprise 词表时无动作的陪衬全员小跳。点名提亮：`findCalledCast` 只认 2 字以上的名字 / 别名，命中条目带 `called`，filter 为 `CAST_CALLED_FRAME`（focus 优先），头部对齐补刷新也保留。陪衬动作 `playCastBeats` 复用 `playSpriteAction`，挂在元素 `_igsCastBeat` 上，下一轮、下台与清层时取消（避免 sink 的 `fill:'forwards'` 停留），渲染层按 `messageId:currentIndex` 每页只播一次。陪衬符号：渲染层把 `marks` 作为 `castMarks` 与 `cast: castFxTargets` 传给 `applyFxToDom`，`playSymbol` 用 `effect.castTarget` 的几何落点，每页只播一次，只开陪衬反应时也运行。戳陪衬：`applyMetaFx` 在 `metaFx.poke` 且陪衬反应开启时为每个在台陪衬放一个热区（`.igs-meta-hot.is-cast[data-igs-meta-cast]`），每页按角色计次（说话人沿用原计数），压扁只对该陪衬元素做 WAAPI `composite:'add'` 缩放、不改 `#igs-stage-motion`，气泡与怒气符号落在该陪衬头部，交互摘要记录被戳角色。

## 硬约束

- 不得用新的 `.igs-*` DOM 替换原版 `.igs-*` DOM。
- `openSettings()` 不得再返回 `settings-ui-not-mounted`。
- `openLatestAvailable()` / `openViewerFromMessage()` 必须能得到 `#igs-overlay` 等价结构。
- 同一时刻最多存在一个 `[data-igs-embedded-host="1"]` 和一个 `#igs-overlay`；关闭、切模式和销毁必须恢复宿主原文。
- 普通翻页必须复用已准备的正文解析结果，不得无条件重跑整楼正文管线。
- 修改模板、样式和字段路径前，先对照 `projects/Immersive Galgame System 原版备份/tavern helper/bridge/src/ui/**` 与 `app/fixtures/igs-ui/*`。
- 线上交流演出由 `readerSettings.chatShow` 控制，默认关闭。聊天块在正文管线最前端折叠为 `[igs-chat#N]` 占位页（`scene/chat-blocks.js`），与开关无关；开启时该页为 `textType: 'chat'`，由 `#igs-chat-layer` 渲染并隐藏对话框，关闭时降级为「名字：内容」文字页。聊天块存在时不启用 DOM 可见文本覆盖。
- 气泡左右只由设置决定：联系人固定侧 → 自己（`selfName` / `{{user}}` / 酒馆用户名）在右 → `unknownSide`；发送者名先匹配联系人主名与别名，再经场景预设 `characterAliases` 归约。联系人以主名为键存为对象（名字不得含 `.`、`|`、`[`、`]`），以便 `data-path` 直接编辑。
- 聊天层点击与对话框、卡片页一致：左半区上一页，右半区走「下一页」。聊天页「下一页」先推进气泡（点击模式一条、自动模式全部），冒完才翻页；同一页重绘保留已冒出条数，翻回已看完的聊天页直接完整显示；关闭阅读器清理自动连发定时器；减少动态效果时不播放冒出动画。收/发提示音由 `chat-sfx.js` 运行时合成，全显时只响一次。
- 聊天消息类型由 `normalizeChatMessageType` 归一为 text / image / voice / sticker / recall，未知类型按文字；撤回转为居中注释行，不播放音效；`[igs-chat-time:…]` 为居中时间行。
- 「正在输入」只在自动连发、下一条为左侧消息、间隔不低于 600ms 且未开启减少动态效果时出现，重绘时保留，冒出、全显、翻页与关闭时移除。
- 头像只接受状态栏头像的 http(s) / data:image 地址，否则显示首字方标；主题跟随经 `chat-themes.js` 映射全部对话框皮肤并以 `--igs-chat-*` 变量下发，联系人自设颜色优先于主题默认色。
- 线上交流注入提示词存于 `readerSettings.chatShow.promptRule`：空串表示使用内置 `CHAT_SHOW_PROMPT_RULE`，与默认一致的内容归一为空；编辑草稿只存在设置面板 asyncState，点「保存提示词」才持久化并刷新注入。
- 系统类角色由 `readerSettings.systemRole`（`system-role.js`）统一定义：`words` 词池匹配时忽略首尾【】[]()等括号且不区分大小写，显式空词池保持为空；空 `font`/`color` 跟随旁白样式。命中的 char 台词页 `textType` 为 `system`，不显示名字（`showName` 开启除外）、不解析立绘、不进状态栏角色；线上交流中命中的发送者渲染为居中提示条，整段只有系统发送者时不开聊天页。
- 返回看过的聊天页由 `chatShow.returnMode` 决定：`full` 一次平铺、`replay` 不分冒泡节奏自动逐条重播（不显示「正在输入」）、`restart` 按冒泡节奏从头开始。收发音色 `chatShow.sound.preset` 取 `CHAT_SFX_PRESETS` 的键，未知值回退 `cute`。
