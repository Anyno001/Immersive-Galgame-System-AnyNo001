# igs-ui

本目录是 IGS 的 `Immersive Galgame System` 原版 UI 等价层。

## 边界

- 保留原版 `.igs-*` selector、`#igs-overlay`、`#igs-unified-settings`、旧 `igs_*` 存储键语义。
- 浏览器环境挂载真实 DOM；Node 模拟测试返回可断言的 snapshot/controller。
- 不在这里实现 scene 解析、preset registry 或 shujuku 业务逻辑；这里只负责阅读器和设置面板视图宿主。
- `embedded` 模式把唯一阅读器根挂到最新 AI 楼层 `.mes_text` 的兄弟容器，禁止把内部 DOM 插入 `.mes_text`。
- 内嵌上下轮只更换阅读源，挂载楼层保持最新 AI 消息；不得调用宿主跳楼。
- 默认皮肤全部阅读模式的收纳与关闭按钮固定悬浮在阅读器右上角，保留 32px 透明点击区；全部工具 SVG 使用 11px 布局框并补偿 `viewBox` 留白，按钮间距为 1.5px、默认低透明度；不得使用工具条底色、描边、阴影或毛玻璃，也不得贴靠对话框。西欧古典皮肤保持原工具栏停靠语义。
- 内嵌选项气泡必须约束在右上工具按钮与底部对话框之间；选项过多时只允许容器内部滚动，不得越出阅读器。
- 内嵌模式不显示“最新回复 / 前 N 轮 / 页数”等进度元数据行。
- 内嵌模式不渲染 IGS 输入框与发送按钮；选项“填入输入框”必须写入酒馆默认输入框，自动发送仍复用统一宿主发送链。
- 内嵌对话框必须完整约束在阅读器容器内：正文区域自行滚动，角色名和分割线不得收缩或被裁出可视范围；增加顶部留白时不得同步扩大左右与底部内边距。
- 内嵌容器桌面比例使用更修长的 `8:5`，移动端高度上限为 `min(74dvh, 680px)`；不得通过放大内部对话框代替容器增高。
- 默认对话框皮肤与全部选项使用霜夜微圆角平面语言；默认对话框无描边，选项仅允许极弱描边，透明度继续由现有玻璃浓度设置控制。
- 默认皮肤的 `readerSettings.dialogHeight` 在电脑浮窗、手机浮窗、楼层内嵌、网页全屏和浏览器全屏模式统一表示插件 iframe 高度比例，档位为 `5% / 8% / 12% / 15% / 18% / 20% / 25% / 30% / 35% / 40%`。自动 loader 必须把源插件 iframe 的高度桥接给父页 bundle，禁止误用酒馆父窗口高度；打开阅读器、切换模式或修改档位时计算一次像素盒高并冻结，同一阅读器实例内的台词长短、分页、流式更新及宿主后续 resize 不得改变该值。历史 `60–600` px 值仅兼容读取并保持原像素高度，改选新档位后保存为比例。正文只在现有 `.igs-text` 内滚动，角色名、分隔线和输入区必须留在框内。`null` 恢复内容驱动的自适应高度及当前模式安全上限。
- `readerSettings.dialogSkin` 只接受 `default` / `western-classic`；缺失或非法值回落 `default`。切换皮肤不得替换 `#igs-dialog`、`#igs-speaker`、`#igs-text`，不得换肤工具栏、选项、背景或正文解析。
- `readerSettings.dialogSkin=gradient-veil` 为第三种可选皮肤：共享默认 `vnTheme`、布局、正文与交互配置，仅新增 `readerSettings.gradientVeil` 的颜色、stage 高度比例、最大不透明度和姓名样式；黑幕使用全宽 `to top` 渐变贴合阅读器左右与底边，不使用毛玻璃，不把渐变写入纯色 `--igs-dialog-bg`。
- 渐变黑幕的姓名样式默认沿用默认主题，可选 `plain-text`；切回 `default` 或 `western-classic` 必须清除黑幕节点显示、专属变量和姓名样式状态，西欧古典主题与姓名牌资产保持隔离。
- 西欧古典皮肤使用内嵌三片背景：高度 `184px`、左右端各 `110px` 保形、中段横向伸缩，常规最小目标宽度 `280px`；正文继续在现有安全区和滚动节点内排版。`readerSettings.classicDialogWidthPercent` 取 `60–100`，默认 `100`，只在电脑浮窗模式按阅读器可用宽度自动计算并居中；手机与楼层内嵌保持原有满宽。
- 西欧古典姓名牌复用 `#igs-speaker` 及其既有显隐条件；常规起点相对主框为 `left:35px; top:-22px`，常规尺寸 `300×50px`，两端各 `40px`、中段占主要宽度。窄屏视口（`max-width:640px`）的五种阅读模式统一使用相对主框 `41.667%` 宽度、`left:38px; top:-14px` 与原始 `50px` 高度；姓名使用 `13px` 深色字与细白描边并垂直居中。无姓名时不得出现空牌，切回默认必须恢复原姓名与分隔线布局。
- `readerSettings.classicVnTheme` 独立保存古典字体、颜色与对齐；`vnTheme` 保留默认皮肤设置，`fontSize` 共用。古典固定推荐高度时只禁用高度编辑、保留旧 `dialogHeight`；共享玻璃设置继续作用于工具栏、选项和数据库，不得为古典对话框全局关闭。
- 无背景图时固定使用霜夜底色 `#16181a`，不提供可配置色盘；历史 `emptyBackgroundColor` 存储字段必须兼容忽略并在下次保存时清除。
- 阅读器设置必须按「对话框 / 画面 / 演出 / 选项 / 顶部UI」五个二级页面分组；切换只改变当前设置视图，不改写设置值。对话框尺寸、皮肤、文字与背景外观统一放入「对话框」；背景图呈现放入「画面」；打字机、分页、人物过场与 NSFW 视觉放入「演出」；工具栏与左上状态栏放入「顶部UI」。重分类只移动展示位置，不得改写既有持久化路径。
- 设置面板提供持久化的夜间/日间配色；日间色板以素白的 `#f1f1ef / #f7f7f5 / #fbfbfa / #e8e8e5` 层级为基准，只作用于 IGS 设置面板。
- 场景设置必须按「规则 / 素材」二级页面分组；素材页内继续保留「场景素材 / 角色立绘」切换。
- 场景条目的 `words` 在设置页作为场景别名管理；角色别名存于 `sceneAssets.characterAliases[主角色名]`。别名只参与名称归约，必须复用主条目的背景、情绪立绘和 `spriteLayouts` 位置键；角色改名/删除及场景预设保存、应用、导入、导出必须同步别名。
- 场景注入提示词输入只更新临时草稿，必须点击右侧「保存提示词」才覆盖持久规则；恢复默认键仍立即恢复并保存，界面必须显示保存状态。
- 「切换模式」分段按钮必须按模式数量动态等宽分配；内部 padding、图标间距、字号与图标尺寸必须随容器宽度收缩，不得用断点或固定 padding 挤压「楼层内嵌」标签。
- 设置主菜单「基础 / 正文替换 / 图像 / 场景 / 阅读器」必须使用五列等宽、文字居中的网格布局。
- 「阅读器 → 顶部UI」页提供左上角状态栏总开关；关闭时不挂载状态栏、不读取数据库、不注册表格更新回调，子设置值保留；开启且当前页有角色时始终显示头像，情绪标签默认开启并可单独关闭；选择表格后才额外显示匹配到的 HUD 条。地点栏可独立开启且仅在旁白页显示；「显示更多的场景信息」开关默认关闭。开启后的状态栏项顺序固定为显示情绪标签、显示地点栏（仅旁白）、显示更多的场景信息、头像圆角、状态栏大小、状态栏背景、HUD 条配色与读取表格多选。
- 「阅读器 → 演出」页提供打字机总开关与快/中/慢三档速度，持久化于 `readerSettings.typewriter.enabled` / `readerSettings.typewriter.speed`，默认关闭、中速。启用后只对新进入的当前正文页逐字显示，保留心理描写等内联结构；播放中首次点击或向后推进只补全当前页，不翻页。系统要求减少动态效果时直接显示全文。
- 地点栏整体尺寸随状态栏大小档位缩放，并在其上叠加独立档位系数（小 1.2 / 中 1.45 / 大 1.7），由 `--igs-hud-location-scale` 作用于地点图标、文字与间距。状态栏大小不再对地点栏无效果。
- 「NSFW 场景隐藏立绘（暗角保留）」与「旁白时立绘变暗」默认均关闭。前者开启时，NSFW 场景在快照装配层即不解析立绘 URL，暗角柔焦帷幕不受影响；若地点栏已开启，NSFW 场景的对白与心理页仍持续显示当前地点，但不显示人物头像与情绪。后者开启时，旁白页立绘仅轻微压暗去饱和（`brightness(0.86) saturate(0.86)`），关闭时立绘原样显示。旁白暗化由开关驱动的跨模式内联样式实现，不再使用内嵌模式专用 CSS 强制覆盖。
- 「NSFW黑幕强度」提供弱/中/强三档（`readerSettings.statusHud.nsfwVeilLevel`，默认 `medium`），只以 CSS 变量 `--igs-nsfw-veil-center` / `--igs-nsfw-veil-edge` 驱动边缘暗角渐变的中心与边缘透明度；背景图本身不加模糊、压暗或去饱和滤镜，黑幕仅为边缘暗角；非 NSFW 场景必须清除两个变量，回落 CSS 内默认值。档位映射表唯一来源为 `status-hud-model.js` 的 `NSFW_VEIL_LEVEL_STYLE`。
- 场景信息取当前 `[igs-scene:地点|时间|天气]`：普通模式显示细线定位 SVG 与地点，详细模式显示定位 SVG 与“天气 · 时间 の 地点”；不使用胶囊、底色或边框。通常人物对白与心理描写页不显示场景信息；唯一例外是 NSFW 场景已关闭人物立绘时，地点栏持续显示当前地点并保持头像、情绪为空，不得改变其他 HUD 条布局。
- 状态栏不显示角色名或表名；角色名仅用于主名/别名归约、头像查找与表格行匹配。情绪标签取当前 `[igs-char:]`/`[igs-thought:]` 的原始情绪值，不得使用已归约的 `spriteMood`；旁白不继承上一句情绪。胶囊无描边、半透明、单行省略。
- 状态栏头像使用独立映射 `sceneAssets.statusAvatars[主角色名]`，不占用情绪立绘槽；在角色卡的别名与情绪立绘之间提供图片地址输入、上传/替换与清除，地址支持 `http(s)` 和 `data:image/...`，别名复用主角色头像，角色改名迁移、删除清理，场景预设保存/应用/导入/导出必须同步。未设置时使用内置透明 SVG 小人。圆角固定六档：方角 `0px`、微圆角 `6px`、小圆角 `10px`、中圆角 `16px`、大圆角 `24px`、圆形 `50%`。
- 状态栏表格选择保存 `{uid,name}` 并保留选择顺序；空选不扫描任何表。数值识别支持 `%`、`当前值/上限` 与单元格内分号多指标，排除日期与时间样式；显式百分比超出 `0–100` 判为非法不显示。读取失败、缺表、缺行只允许省略 HUD 条，不得显示成 `0%`，也不得隐藏当前角色的头像与可选情绪标签。
- 右侧 HUD 最多显示四条，顺序为所选表顺序再到表内字段顺序；末尾数值使用固定等宽列左对齐，使各 HUD 条右端一致。超出部分以 `+N` 提示且不占第五行；一至四条在身份区高度内均匀分布。大小档在响应式倍率（小 `0.86`、中 `1.00`、大 `1.16`）计算完成后统一乘 `0.8`，并同步缩放头像、圆角、间距、胶囊、文字、进度条与折叠控件。
- HUD 条配色仅允许 `彩色` 与 `灰白`；默认彩色并保留信任、好感、了解及稳定色槽，灰白统一使用中性渐变，不改变数值、排序、轨道或标签。
- 状态栏背景使用与 HUD 条配色一致的分段可选按钮，仅有两种：`无背景` 不绘制底板；`跟随对话框` 使用默认对话框背景色的 `50%` 透明混合，复用对话框模糊并使用更小的 `6px` 缩放圆角，不新增独立透明度字段。展开态不显示减号，整块状态栏作为透明收起按钮；折叠态仅显示加号用于展开。选项气泡显示时抑制，顶部固定工具栏时下移，楼层内嵌避开右上工具按钮。
- 首版只为默认皮肤建立状态栏视觉契约；不得修改西欧古典对话框资产、固定高度与姓名牌契约。
- 内嵌模式只对最新 AI 楼层的 `.mes_text` 做 `display:none !important` 视觉隐藏；不得删除、替换或清空该节点及其文本，关闭或换楼层时必须恢复原始显示值和优先级。
- IGS 阅读器、设置页和数据库面板的所有滚动区域保留滚动能力，但不得显示原生滚动条。
- 流式观察只在内嵌阅读器打开时启用；生成期间必须持续隐藏最新 AI 楼层原文并只显示载入态，宿主结束事件后一次性解析，结束后的普通 DOM 更新不得重新点亮动画。
- 打字机演出默认关闭，开启后提供快 / 中 / 慢三档并按 Unicode 字素逐步显示当前页文字；必须保留心理描写等内联节点结构。当前页演出期间首次点击正文、按空格或向右推进只补全本页，下一次推进才翻页；同页因图片、状态栏或设置刷新而重渲染不得重新播放，系统启用“减少动态效果”时直接完整显示。
- 当前消息不存在任何 `[igs-scene:]`、`[igs-char:]`、`[igs-thought:]` 指令时，所有文段必须强制按旁白分类，禁止根据文本外形猜测台词或心理话。
- `[igs-scene:]`、`[igs-char:]`、`[igs-thought:]` 与旁白写在同一段时，必须以指令闭合 `]` 为分界断行：`]` 之后的文本属于旁白，不得被并入台词或心理话正文，也不得进入气泡。
- 阅读器分页、场景状态和立绘应用必须消费同一份最终分页结果；按句分页形成的旁白页不得提前应用后续角色或场景指令。
- 旁白页保留最近已出场角色的立绘并降低亮度与饱和度；标准 `filter`、`-webkit-filter` 与内嵌状态类兜底必须一致，进入台词或心理页后恢复原色。
- 默认皮肤各模式的对话框复用楼层内嵌的内距与框内裁切视觉；模式自身的容器尺寸、目标对话框高度、输入区显隐和挂载方式保持不变，不得修改西欧古典对话框资产。
- 震动演出读取当前角色指令保留的原始 `content.statusEmotion`，默认关闭、强度默认中档；用户可编辑中文触发词，显式空词表保持为空，不扫描台词正文、不匹配英文、不依赖 `moodGroups` 或 `spriteMood`。
- 震动只作用于 `#igs-stage-motion` 内部舞台包装层，支持弱/中/强三档；同一消息同一页同一情绪的重绘不重复播放，关闭阅读器和减少动态效果模式必须清理或跳过演出。

## 硬约束

- 不得用新的 `.igs-*` DOM 替换原版 `.igs-*` DOM。
- `openSettings()` 不得再返回 `settings-ui-not-mounted`。
- `openLatestAvailable()` / `openViewerFromMessage()` 必须能得到 `#igs-overlay` 等价结构。
- 同一时刻最多存在一个 `[data-igs-embedded-host="1"]` 和一个 `#igs-overlay`；关闭、切模式和销毁必须恢复宿主原文。
- 普通翻页必须复用已准备的正文解析结果，不得无条件重跑整楼正文管线。
- 修改模板、样式和字段路径前，先对照 `projects/Immersive Galgame System 原版备份/tavern helper/bridge/src/ui/**` 与 `app/fixtures/igs-ui/*`。
