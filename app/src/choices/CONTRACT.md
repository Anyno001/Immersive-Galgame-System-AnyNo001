# choices 模块契约

## 职责

- 管理 Immersive Galgame System 选项浮窗。
- 支持选项组件 Mod 在选项浮窗页导入、导出、列表管理。
- 支持选项解析预设。
- 点击选项后必须写入酒馆输入框并触发发送按钮，不能绕过输入框直接创建消息。

- 检定建议表的「骰子命令」在点击时由 `dice-check.js` 判定：通过骰子系统公开 API `window.AcuDice` 查属性、掷骰，结果以 `<meta:检定结果>` 块随展示文本一起经输入框发送；不得触发骰子系统自带的发送（它绕过输入框）。骰子系统不可用或数据缺失时按原命令文本降级，禁止伪造骰点。

## 原因

shujuku 有剧情推进功能，绕过输入框直接发送可能导致剧情推进不触发。
